## 3. 已知限制

1. 播放的真实剧集 CDN（vip.lz-cdn*.com）在本机被两件事挡住：系统代理分流
   （Clash 出口 404）与无头浏览器指纹（404）。**用户日常浏览器加直连规则
   `DOMAIN-SUFFIX,lz-cdn*.com,DIRECT` 后即可播放**；真实部署环境不受影响。
2. 暴风资源 CDN（c1.rrcdnbf6.com）本机网络完全不可达——多资源站容错待做。
3. 目录同步无调度器：当前为管理端点手动触发；增量模式建议后续加周期调度。
4. 同步把增量窗口内非动漫分类条目也入了库（265 条，属预期，前端按分类筛选）。
5. Bangumi 富化 / 新番时刻表 / 多线路切换 → M9 范围。
