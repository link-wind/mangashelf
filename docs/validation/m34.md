# M34 验证：漫画首页/切换/阅读性能

日期：2026-11-11（本地实测）

## 改动

- 服务端分区缓存（10 分钟）+ API 启动预热（4.4s，后台）。
- 浏览器解析结果磁盘缓存（`server/data/manga-browser-cache`，30 分钟）。
- Python：页图可一次取全时跳过滚动；goto 后等 load + URL 稳定；镜像空壳重载重试。
- 前端首页 localStorage 缓存 10 分钟，切换源先渲染缓存；阅读器滚动 100ms 节流 +
  图片列表缓存。

## 实测

| 场景 | 结果 |
|---|---|
| 首页首次出现分区卡片 | 263ms |
| 切换「拷贝漫画」 | 110ms |
| 冷启动后 `/manga-discovery` | 15ms（预热已填充） |
| 腾讯/哔哩/拷贝 `/sections` 命中缓存 | 7~11ms |
| 拷贝详情/页图 冷 | 7.8s / 5.4s |
| 重启后拷贝详情/页图（磁盘缓存） | 15ms / 8ms |
| 包子章节页图（站点可达时） | 6s（原 14s） |

## 已知限制

- 浏览器源首次解析仍为 5~8s（Playwright 启动 + 站点 JS），之后走缓存；
- 上游抖动：包子站点间歇性 `ERR_CONNECTION_CLOSED`；嬉皮章节 API 偶发 18s；
- 包子部分章节为锁定/空内容，返回 NO_PAGES（显式 502）。
