# M15 验证记录：漫画专区

> 日期：2026-11-09 · 变更：implement-manga-section（已归档）
> 结论：漫画从「藏在作品详情里」提升为独立专区：`/manga` 索引 + `/manga/:id` 详情 +
> 首页漫画区块；封面自动取章节首页缩略图，无需额外交付。

## 1. 页面与接口

| 项 | 说明 | 结果 |
| --- | --- | --- |
| `GET /api/v1/manga` | 仅列「有已发布章节」的可见作品；游标分页 + 标题搜索 | ✅ 24 部/页 |
| `GET /api/v1/manga/{id}` | 作品 + 章节（含逐章已读页数）+ 封面 + 续读目标 | ✅ |
| 封面 | 首章首页 `thumbnail_asset`，缺失回退阅读图 | ✅ 图片渲染 |
| `/manga` 索引 | 封面卡、话数、更新至第 N 话、搜索、加载更多 | ✅ 截图 |
| `/manga/:id` 详情 | 封面/简介/状态/继续阅读（服务端进度）/章节列表/管理素材 | ✅ 截图 |
| 首页漫画区块 | 继续阅读（进度角标）+ 漫画更新 12 部 | ✅ |
| 导航 | 新增「漫画」，移除「我的素材」（页脚与书架仍可进入） | ✅ |

## 2. 设计要点

- **封面零成本**：M1 已为每页生成缩略图，直接取首章首页缩略图做封面；
  无缩略图回退阅读图。避免为漫画再引入一套封面上传流程。
- **可见性复用**：与 works 完全一致（本人 或 PUBLIC+PUBLISHED），只额外要求
  `chapter_count > 0`，避免空作品淹没索引。
- **续读**：优先取该用户最近阅读进度（chapter + 页序），无进度则首章首页。
- **逐章已读**：详情页每行标注「读到第 N 页」，按钮变「继续」。

## 3. 已知限制

1. 未提供自定义封面（后续可在素材管理加「设为封面」，写 `works.cover_asset_id`）。
2. 索引无标签/分类维度（漫画目前只有标题与描述）。
3. 阅读器仍是分页窗口模式，未提供「条漫连续滚动」模式。
4. 无章节评论/弹幕。
