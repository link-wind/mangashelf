## 2. 关键实现事实

- **Embedding**：Spring AI 2.0.2 transformers + 本地 e5-small-v2 ONNX（384 维，
  模型文件经 hf-mirror 下载至 `server/models/`，不入库；`mangashelf.embedding.enabled`
  门控装配，官方自动配置排除——模型缺失不阻塞启动）。e5 约定 query/passage 前缀。
  维度 384 经本机真实产出向量后由 V6 迁移固定（DESIGN 8.2"首个已验证模型固定维度"）。
- **OCR**：RapidOCR（PP-OCRv5/6 系列模型随包缓存）本地推理，中英文实测可用；
  无文字页如实空串（规格场景）。
- **双队列**：content.index 队列落地（DESIGN 11.1），index.build 任务种类 + 目标 CHECK。
- **RRF 合并**（k=60）：标题/章节名（ILIKE+similarity）、OCR 字面（trgm %）、
  语义（cosine）三路；SQL 前置授权过滤（owner 或 PUBLIC+PUBLISHED，DESIGN 3.3）。
- **QA**：证据 ID（S1…Sn）服务端注册、素材文本不可信系统提示、SSE 流式、
  引用 ID 校验（无效 ID 丢弃）；无 ChatClient bean 时 503。

## 3. 评估（scripts/eval-m4.sh 可复现）

- 素材：固定 6 页中文漫画（每页 2–3 句标注内容），15 条标注查询（覆盖台词/事件/
  地点/语义词改写）。
- 结果（合并通道，目标页 Recall@K）：**Recall@1 = 14/15 = 93%**、Recall@3 = 93%、
  **Recall@5 = 15/15 = 100%**。唯一未进 Top3 的查询"旧书店的猫叫什么名字"
  （语义改写较大）在 Top5 命中。
- 规模边界：完整目标为 30–50 条人工标注集（DESIGN 21.2）；本阶段交付可复现的
  固定 15 条小集，扩大标注集是后续明确事项。不以此冒充泛化结论。

## 4. 过程中的工程修复

## 5. 已知限制（进入 M5 前的边界）

1. 页级索引：单格级/片段级索引未实现（DESIGN 15.2 后续）；RapidOCR 对手写字体/
   特殊排版的召回有限。
2. 语义效果基于 15 条小集的定性观察（e5 对中文语义词改写实测可用）；
   不承诺泛化结论（21.2 写作限制）。
3. QA 无对话模型期间为 503；接入对话渠道（云端 Key 或本地推理）属后续配置事项。
4. 索引重建需先无 ACTIVE 批次（409）；自动重建策略（来源变更检测后自动重跑）
   未实现。
5. search:read 已对 Bearer 开放 /search 与 /qa；MangaWeaver 侧尚未使用检索能力。
