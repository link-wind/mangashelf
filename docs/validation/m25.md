# M25 验证：多源聚合推荐（中文源）

日期：2026-11-10（真实源 + 浏览器实测）

## 实现

- `MangaSource.language()`：腾讯动漫/哔哩漫画 = `zh`，MangaDex = `multi`；
  `/manga-sources` 返回 language。
- `MangaDiscoveryService`：只聚合 `language=zh` 且有 RANK 的源；虚拟线程并行
  抓取，单源 15s 超时/失败隔离；RRF（k=60）融合 + 标题归一化去重 +
  中文标题过滤；结果缓存 10 分钟。
- `GET /api/v1/manga-discovery?limit=12`：首行综合热榜 + 各源分区 + errors。
- 非中文阅读源降级：哔哩榜单桥接到 MangaDex 的条目改为 `readable=false`、
  点击打开哔哩官方页（避免从中文首页进入非中文源阅读）。
- 前端：源 chips 增加「综合」并默认；综合模式显示多源 hero + 综合热榜 +
  各源分区（标注源名）；源列表只显示中文源。
- 外部搜索页只保留中文源（移除 MangaDex chip）；空关键词不自动请求。

## 实测

- 源列表：bilibili zh / mangadex multi / tencent zh。
- 冷缓存首次聚合 5.3s（哔哩桥接匹配 + 腾讯 4 次抓取并行），无 errors；
  缓存后返回 <50ms。
- 综合热榜 12 条：传武、一人之下、绍宋、大奉打更人…；来源为
  tencent + bilibili（后者全部降级为站外）。
- 各源分区：哔哩热门 12、腾讯编辑推荐 12 / 飙升 6 / 畅销 10 / 新作 10 /
  真香 10。
- 浏览器（1280×720）：
  - 默认「综合」；hero 显示「多源聚合 · 综合热榜」；综合热榜前三名角标；
  - 站外条目显示「站外」角标；
  - chips 只有 综合/哔哩漫画/腾讯动漫，MangaDex 不再出现；
  - 外部搜索页仅腾讯动漫 chip，搜「航海王」返回 3 条并可进详情。
- 测试 20/20 通过（RRF 累加/去重、中文过滤、版本后缀区分、multi 源排除、
  非中文阅读源降级、缓存）。

## 已知限制

- 冷缓存首次打开综合页约 5s（哔哩跨源桥接），之后 10 分钟内秒开；
- 去重是标题级，极少数别名/简繁差异仍会重复（作品级合并留待方案 C）；
- 哔哩条目统一降级站外（因站内可读入口均为 MangaDex）；
- 物理未删除 MangaDex，旧链接/阅读器仍可用，只是不再出现在首页与搜索入口。
