## 2. 实现要点

- 日历接口补 `remarks/episodeCount/categoryName`（hero 的集数与更新进度来自资源条目）。
- Banner 背景用封面图轻微模糊（5px）+ 暗色渐变遮罩：竖版封面素材下仍可辨识画面、
  文字对比度足够；缩略图列表直接复用同一批条目。
- 「追番」= 物化（如需）+ `PUT /me/library/{workId}`，随后跳作品页。
- `/anime?category=` 支持深链，首页分类 pill 直达对应筛选。

## 3. 已知限制

1. 无宽幅剧照素材，Banner 背景是竖版封面裁切+模糊，信息密度不及参考站。
2. 「热门」只有 Bangumi 评分维度，没有播放量/追番人数统计。
3. 最近更新来自资源站目录，非逐集更新流。
