## 2. 实现要点

- 日历接口补 `remarks/episodeCount/categoryName`（hero 的集数与更新进度来自资源条目）。
- Banner 背景用封面图轻微模糊（5px）+ 暗色渐变遮罩：竖版封面素材下仍可辨识画面、
  文字对比度足够；缩略图列表直接复用同一批条目。
- 「追番」= 物化（如需）+ `PUT /me/library/{workId}`，随后跳作品页。
- `/anime?category=` 支持深链，首页分类 pill 直达对应筛选。

## 3. 已知限制

1. 无宽幅剧照素材，Banner 背景是竖版封面裁切+模糊，信息密度不及参考站。
2. 「热门」只有 Bangumi 评分维度，没有播放量/追番人数统计。
3. 最近更新来自资源站目录，非逐集更新流。

## 4. 补记（2026-11-09）：「剧照」数据源查明并落地

参考站 Banner 并非独立剧照库——实测其 `.hero-art` 的背景图是
`https://bgmimg.anibt.net/pic/cover/l/67/5a/555605_cLCw5.jpg`，即 **Bangumi 大图封面**
（`/pic/cover/l/`，1200×1698），CSS 以 `background-size: cover` + 渐变遮罩铺满，
无模糊。

据此调整：

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 封面尺寸 | `images.common`（150px，模糊） | 同步改用 `images.large`（1200×1698，260KB） |
| Banner 背景 | 5px 模糊补偿 | 无模糊，`cover` 裁切 + 暗色渐变（与参考站一致） |
| 卡片封面 | 同用大图（慢） | 代理支持 `?size=large/medium/common/small`，卡片用 medium |
| 回源 | 每次请求上游 | 磁盘缓存 `data/covers/{subjectId}-{size}.jpg`，命中约 0.1s |

实测：Banner 为清晰宽幅key visual；首页 39 张卡片封面全部正常渲染。
