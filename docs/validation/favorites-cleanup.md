# 我的收藏页面与本地测试数据清理

日期：2026-11-12，Asia/Shanghai。

## 页面改造

- `/shelf` 页面标题与顶部导航、页脚、漫画详情页按钮统一使用「我的收藏 / 加入收藏」。
- 页面分为「动漫」和「漫画」两个 Tab，并显示各自条目数。
- 动漫 Tab 读取 `GET /api/v1/me/watch-history?limit=100`，展示最近观看和续播入口。
- 漫画 Tab 汇总 `GET /api/v1/me/library` 的收藏、本地阅读进度，以及
  `GET /api/v1/me/manga-progress?limit=50` 的外部漫画阅读记录。
- 三个请求使用 `Promise.allSettled`：单个接口失败时其余内容仍可显示，失败原因在页面提示。

## 已知限制

当前后端没有独立的动漫收藏表，动漫 Tab 因而使用观看历史作为数据来源；它表示
「最近在看」，不等同于用户主动收藏。若需要严格的追番收藏语义，需要另建收藏表、
收藏端点与番剧详情页操作入口。
