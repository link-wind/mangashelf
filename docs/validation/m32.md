# M32 验证：声明式浏览器漫画源（包子漫画）

日期：2026-11-11（真实站点 + 本地 Playwright + 浏览器）

## 实现

- `processing/tasks/browser_plan.py`（task=manga.plan）：按 browserPlan 执行
  搜索/详情/页图提取；字段支持 select/attr/attrs/regex/text/last；支持点击
  展开与滚动；页图支持 HTML 正则全量提取并按路径去重。
- `BrowserPlanMangaSource`：规则行含 browserPlan 时自动实例化，能力按节推导；
  章节 ID `{mangaId}|{slot}`。
- V19 包子漫画规则（SEARCH/DETAIL/READ），无需 Java 站点代码。

## 实测

| 环节 | 结果 |
|---|---|
| 搜索「海賊王」 | 4 条（海賊王、yellow、艾斯、學院），约 5s |
| 详情 | 航海王 1187 话，约 5s |
| 章节页图 | slot 0 共 50 页（150 条跨 3 个 CDN 按路径去重），约 14s |
| 前端详情 | 1187 话，来源 chip 包子漫画，切换源按钮（拷贝/腾讯） |
| 前端阅读器 | 25 组双页，页图正常加载 |

## 已知限制

- 包子详情页不直出章节标题，先按 `chapter_slot` 序号生成；阅读页仍显示真实标题。
- 包子/漫蛙站点连通性偶发抖动，失败时显式 502，不影响其他源。
- 搜索结果为懒加载封面时可能显示默认封面（详情页封面正常）。
