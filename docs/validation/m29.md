# M29 验证：漫画浏览器解析源（拷贝漫画）

日期：2026-11-11（真实站点 + 本地 Playwright + 浏览器实测）

## 背景

拷贝漫画应用 API 对本机出口 IP 持续 210；网页版 `www.copy4000.com` 可直连，
但章节图由前端 JS 用 `contentKey` 解密（游客 `contentKey=''` → 0 页）。
复制动画 Worker 的「无头浏览器执行 JS + 前端直连 CDN」方案。

## 实现

- `processing/tasks/manga_resolve.py`：`detail` 打开详情页点「目錄」解析
  标题/封面/简介/章节；`chapter` 打开章节页滚动触发 lazysizes，收集解密后
  `img[data-src]`；仅允许 `https://www.copy4000.com/` URL。
- `MangaBrowserResolveService`：调用固定 Python 入口，单并发、缓存 10/30 分钟，
  任务目录解析后递归删除（task.json 含 Cookie）。
- `CopyMangaBrowserSource`（id=copymanga）：RANK 走公开 API（版本自举），
  DETAIL/READ 走浏览器；章节 ID `{pathWord}~{uuid}`。
- V18 删除旧 RANK-only 规则行；注册表代码源优先。
- 登录助手 `processing.manga_login`：本机可见浏览器登录一次，保存 storage_state。

## 实测结果

- 源注册：`copymanga` = DETAIL/RANK/READ，language=zh。
- 榜单：5 条（寶石魔女、只是體檢而已…），1.3s。
- 详情（匿名）：39 话，7s；顺序为第1话…第二季第11集（页头伪链接已过滤）。
- 章节（匿名）：2 张 664×4897 长条图，10s；CDN 直连 200（313KB）。
- 前端：`/manga-ext/baoshimonv?source=copymanga` 详情 39 话；
  点第1话进入阅读器，2 张图全部加载，URL 为
  `/manga-ext/read/baoshimonv~{uuid}`。
- 测试 23/23 通过。

## 配置（本机开发）

```bash
# 系统 python 没有 playwright，必须指定处理环境解释器
export MANGASHELF_PYTHON=$PWD/processing/.venv/bin/python
export MANGASHELF_PROCESSING_ROOT=$PWD
# 需要登录态时（可选；当前匿名可读部分章节）
export MANGASHELF_COPYMANGA_STORAGE_STATE=$PWD/data/copymanga-state.json
```

登录态生成：

```bash
processing/.venv/bin/python -m processing.manga_login
# 浏览器里登录后回终端回车；文件默认 data/copymanga-state.json
```

## 已知限制

- 详情/章节首次解析 7~10s（浏览器启动 + JS 解密），缓存后秒开；
- 付费/锁定章节无页图，显式报错，不破解；
- 长条图在双页模式下并排显示，建议 webtoon 类作品切单页滚动模式；
- Worker 容器需自带 Playwright（M5 镜像已烘焙）与 `MANGASHELF_PYTHON` 指向
  OCR venv。

## 追加：长条漫自动滚动（M30）

- 阅读器预加载前 2 张页图，高/宽 ≥3 判定长条漫，强制滚动模式并显示
  「长条漫 · 滚动」；手动切换页模式优先（仅本章节）。
- 实测：拷贝漫画章节（664×4897）即使 localStorage 保存双页也自动滚动，
  2 张图全部加载；腾讯航海王（800×1132）保持双页模式。

## 追加：详情页切换数据源（M31）
