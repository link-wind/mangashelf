# M26 验证：跨源同作合并

日期：2026-11-10（真实源 + 浏览器实测）

## 实现

- 聚合推荐在 RRF 之后增加**作品聚簇**：条目按得分降序依次归簇——归一化标题
  精确相等或相似度 ≥0.9（`MangaMatcher.similarity`，二元组 Jaccard）视为同作。
- 聚簇得分累加；展示条目优先中文源站内可读版本；`sourceCount`/`sources`
  记录成员源（源名映射）。
- `DiscoveryItem` 摊平为 RankItem 字段 + `sourceCount`/`sources`（首版嵌套
  结构导致前端 hero `.slice` 崩溃，已修复并留决策记录）。
- 前端：`sourceCount>1` 的卡片显示蓝色「N 源」角标（title 提示源名单）；
  hero chips 显示「N 源」。

## 实测

- 综合热榜：航海王合并为「2 源 [哔哩漫画, 腾讯动漫]」，展示腾讯可读版本
  （更新到1198话）；其余 11 条各 1 源。版本区分正确：
  「航海王（全彩版）」「航海王（番外篇）」未误合并（搜索页验证）。
- 点击合并卡 → `/manga-ext/505430?source=tencent`（进入可读源详情）。
- 浏览器渲染正常（root 32KB，2 源角标出现，hero chips 含「更新到1198话 /
  2 源 / 站内可读」）。
- 测试 23/23 通过：跨源合并 + sources 汇总、版本后缀不误合并、
  仅空格/标点差异合并、可读版本优先为代表、中文过滤、multi 源排除、
  非中文阅读源降级、缓存。

## 排障记录（关键）

- 首版 `DiscoveryItem(item, sourceCount, sources)` 为嵌套 JSON，前端按扁平
  RankItem 读取，`hero.title` 为 undefined → `.slice` 崩溃整页白屏
  （React 19 未捕获渲染错误不进 console.error，靠 `createRoot` 的
  `onUncaughtError` 钩子把错误写进 document.title 才定位）。
  决策：服务端摊平输出（前端零改动即兼容）；main.tsx 保留错误钩子。

## 已知限制

- 相似度阈值 0.9 只覆盖写法差异；完全不同译名（如「海贼王」vs「航海王」）
  不合并，需别名词典（不做）。
- 聚簇为请求内存态，无持久化作品 ID。
