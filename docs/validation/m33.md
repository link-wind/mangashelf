# M33 验证：嬉皮漫画声明式源

日期：2026-11-11（真实站点 + Playwright + 浏览器）

## 实现

- browserPlan 新增 `detail.chaptersApi`（分页 JSON API，自动按 total_pages 翻页）。
- pages 变量通用化：`{chapterId}` 原样 + 可选 `{comicId}`/`{slot}`。
- V20 嬉皮漫画规则（SEARCH/DETAIL/READ），无 Java 站点代码。

## 实测

| 环节 | 结果 |
|---|---|
| 搜索「海贼王」 | 4 条，5s |
| 详情「海風盤旋時」 | 50 话，6.5s（API 1 页） |
| 章节页图 | 41 页，5.5s |
| 前端详情 | 50 话，chip 嬉皮漫画，切换源含 拷贝/腾讯/包子 |
| 前端阅读器 | 21 组双页，图片全部加载 |

## 漫蛙结论

漫蛙详情/章节/搜索均可达，但章节图由前端 fetch 后生成 `blob:` URL，
无法作为持久 URL 交给站内阅读器（需另做浏览器取字节→对象存储管线）。
本期不接入，避免「只能看不能读」。

## 已知限制

- 嬉皮章节标题来自 API（完整）；
- 包子章节标题仍是序号生成（详情页不直出列表）；
- 站点连通性偶发抖动，失败显式 502。
