## 3. 过程中的工程修复（真实环境暴露）

| 问题 | 修复 |
| --- | --- |
| 上传资产一律 ORIGINAL，与动画绑定要求的 VIDEO/SUBTITLE 种类冲突 | 资产 kind 由上传 purpose 决定 |
| 版本发布后动画容器仍 DRAFT，读者不可见 | 版本发布随事务流转容器 DRAFT/WITHDRAWN → PUBLISHED |
| 页级关联授权误用 requireOwnedRevision（读者非所有者被 404） | 新增 `requireReadableRevision`（与阅读清单同一判定） |
| 冒烟轮询循环耗尽后静默继续，掩盖真实失败 | 三处轮询补后置断言（核对 smoke-m0） |

## 4. 已知限制（进入 M3 前的边界）

1. 不推断 video_start_ms → panel_id 秒级映射；页码范围定位即止（DESIGN 13.2）。
2. 无声视频如实上报 has_audio=false，不伪造合格标签；编码基线（h264/vp9/av1 + aac/mp3/opus）
   待浏览器矩阵实测后锁定（DESIGN 13.3）。
3. 取消仍在阶段边界生效，运行中的 ffmpeg/ffprobe 子进程不中断（M5 收口）。
4. 动画来源下拉仅列出自己作品的当前版本；跨用户改编授权是后续明确需求（DESIGN 3.2）。
5. 播放器签名过期需刷新页面重新取 playback（短有效期是安全边界，DESIGN 3.3）。
6. Watch 页进度保存按 timeupdate 节流（≥4.5s），关闭页面前最后一次写入不承诺不丢（DESIGN 14.3）。
