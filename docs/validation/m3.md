## 2. MangaWeaver 侧真实端到端（其仓库变更 integrate-mangashelf-platform，commit 609ba65）

1. **真实导入**：`mangaweaver shelf-export --chapter-revision-id <id> --output …` →
   3 页下载、逐页 SHA-256 核验通过、`mangashelf_manifest.json` 落盘
   （含 platform_id / 来源 ID / 每页文件与摘要——协议 17.2 "保存平台与页面来源"）。
2. **成片发布回传**：`mangaweaver shelf-publish --title … --source <crv>:1:2 --video film.mp4` →
   草稿（幂等键 mw-real-…）→ 预签名上传 → 平台 ffprobe 验证 → 发布 →
   回执 `PUBLISHED + watch_url`（receipt JSON 落盘）。
3. **站内闭环**：playback 200（5000ms，Range 206）、来源《月下的信》第 1 话 1–2 页、
   页级关联查询返回该动画；浏览器实测：阅读页显示"观看这段动画（第 1–2 页）"→
   点击 → 播放器真实出画（readyState=4）→ 回到原作入口。

## 4. 已知限制（进入 M4 前的边界）

1. 同键并发双提交的去重以查询实现（本地单客户端顺序调用下窗口可忽略）；
   多端并发需唯一索引方案（需 denormalize owner，design.md D4 记录）。
2. search:read scope 已定义但语义检索端点属 M4。
3. 动画分组：publication 新键默认创建新动画，显式换版经可选 animationId
   （协议文档已含；如客户端需要自动分组，将来加协议字段）。
4. MangaWeaver 侧为最小 CLI 客户端：桌面 UI 集成、导出页直接进预处理流水线、
   成片自动关联创作会话，均属其仓库后续变更。
5. Token 过期时间创建时固定，暂无续期。
