# M22 验证记录：阅读器对齐 HOMURA-reader 设计

> 日期：2026-11-09 · 变更：implement-reader-homura（已归档）
> 结论：移植 HOMURA-reader 的手势判定与交互规则，新增阅读方向、双页（首页单排）、
> 翻页动画、Esc 逐层退出；均已实现并在 One Piece 第 1 话实测。

## 1. 移植内容（对照 HOMURA-reader）

| HOMURA 特性 | 实现 | 实测 |
| --- | --- | --- |
| 点击分区（左30%上一页 / 右30%下一页 / 中40%切换浮层） | `tapZone()` + 双页/单页模式生效 | ✅ |
| 手势判定（tap<300ms 且 <8px；横向滑动 |24px| 且 >14% 宽度或速度>0.45） | `classifyGesture()` 判别联合返回 | ✅ 编译通过 |
| 阅读方向 LTR / RTL（日漫，翻页反转） | 设置面板切换，tap/swipe/按钮全部反转 | ✅ 逻辑就绪 |
| 单页 / 双页 / 首页单排 | `buildSpreads()`：cover 单排后两两成组，RTL 组内反转 | ✅ 双页实测（27 组） |
| 翻页动画：柔和淡入 / 极速无动画 | spread/page 变化时 key 重挂载触发 CSS 淡入 | ✅ |
| 工具栏 2.2s 自动隐藏 | show-ui 类 + 定时器，设置面板打开时不隐藏 | ✅ |
| 快捷键 ←→↑↓（RTL 反转）/ Space / Esc 逐层退出 / F 全屏 | 键盘监听 | ✅ 逻辑就绪 |
| 阅读器隐藏站点导航 | `body.reader-open` | ✅ 截图确认沉浸 |

## 2. 实测（One Piece 第 1 话，lang=en）

- 双页模式：27 组 spread，跨页并排显示（截图确认）
- 设置面板：阅读方向 / 页模式 / 翻页动画 / 清晰度 四行可切换
- 单页 ↔ 双页切换正常
- 沉浸模式：站点导航隐藏，黑底全屏

## 3. 已知限制

1. 横向「跟手」翻页（拖拽跟手 + 不足回弹）未实现，仅滑动判定翻页。
2. 双页模式下页码滑杆以「组」为单位。
3. 阅读方向/页模式等设置全局持久化（未按作品分别记忆）。
4. 本地漫画阅读器（/read/:revisionId）未接入方向/双页设置（其分页窗口模式结构不同）。
5. 单页模式下点击左右 30% 分区翻页在滚动模式下不生效（保留原生滚动），仅双页生效。
