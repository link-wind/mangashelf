## 3. 已知限制

1. 弹幕未做（弹弹play 协议兼容与合规评估延后）。
2. 追番更新红点未做（需目录集数变化检测）。
3. 单集失败不自动换线：提供手动切线路 + 重新解析；自动换线需失败原因分类。
4. 解析限流为进程内滑动窗口，多实例部署需集中计数。
5. 已物化的旧作品保持单线路数据；重新物化才会写入多线路（可后续加「刷新线路」）。
6. 本地播放仍受 CDN 可达性影响（系统代理分流/浏览器指纹），部署环境不受影响。
