## 已验证项

### Python 处理协议（DESIGN 12.2）✅

- `python -m processing.run --task task.json` 固定入口运行通过；stdout 仅 JSONL 进度事件
  （seq/type/stage/message），日志走 stderr，`result.json` 含产物相对路径、页序、role、
  content_type、宽高、字节数与 SHA-256。
- 产物宽高字段已按 Java 端需要补充（MangaWeaver book.json 缺失该项，见探索记录）。
- **路径越界拒绝**：inputs 指向任务目录外（`../../etc/hosts`）→ 进程 exit 1、
  result.json `status=FAILED`，符合 upload-pipeline 规格场景。

### 对象存储选型（回应 DESIGN 24.1-3）⚠️ 有变更

实测结论：

1. **MinIO 官方镜像已从 Docker Hub 撤下**（`minio/minio` pull 报 pull access denied）。
2. `quay.io/minio/minio` 经 Docker Desktop 内置代理稳定返回 401（宿主 curl 可达，
   判定为 Docker 代理链路问题）；`quay.m.daocloud.io`、`docker.m.daocloud.io` 均 403。
3. 开发存储改用 **SeaweedFS**（`chrislusf/seaweedfs`，Docker Hub 可拉取）：
   master+volume+filer+s3 单进程，S3 层支持 sigv4 预签名 PUT/GET 与 Range，
   桶在首次 PUT 时自动创建，静态密钥经 s3.json 注入。

预签名 PUT/GET、过期签名拒绝、Range 与 CORS 行为待下方"上传链路"验证后回填。
