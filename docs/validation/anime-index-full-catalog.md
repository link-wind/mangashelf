## 实施发现

- **误导性统计**：页面「资源目录共 3 部」是筛选后 total 的残留展示（用户看到的 3 部实为
  genre=热血 测试残留），全量 7511 条一直在库中——「写入数据库」无需新增同步，重构展示即可。
- **python str.replace 静默失败**：多行替换锚点不匹配时无报错，导致 season 过滤块漏加、
  运行中 jar 未重打包两层问题叠加。教训：批量替换后必须 grep 验证。

## 已知限制

- 本季新番筛选依赖 Bangumi 关联（68/7511），未关联的本季条目不出现在该视图（与原
  SeasonSection 的「资源已覆盖 68 部」口径一致）。
- 类型 tab「本季新番」与数字分类互斥切换（一次一个维度），与原交互一致。
