> 日期：2026-11-09 · 变更：implement-manga-ui-revamp（已归档）

## 1. 页面改版

| 页面 | 之前 | 现在 |
| --- | --- | --- |
| 漫画索引 `/manga` | 热门横滚 + 本地网格 | **两栏**：左主区本地漫画（搜索/网格/分页）+ 右侧栏**热门榜纵向榜单**（序号/封面/更新/站内可读）与外部漫画入口 |
| 外部详情 `/manga-ext/:id` | 列表式 | **大封面 + 信息 chips + 简介折叠 + 开始/继续阅读 + 章节数字格**（语言、正序/倒序切换；One Piece 实测 451 话） |
| 本地详情 | 无改动（已有章节列表） | — |

## 2. 阅读器改版

外部与本地阅读器统一为哔哩哔哩漫画式沉浸布局：

- 黑底全屏、**隐藏站点导航**（`body.reader-open`）
- 顶栏：返回 / 作品名 / 章节名 / 设置
- 底栏：上一话（页）/ 页码 + 滑杆 / 下一话（页）
- 浮层 3 秒自动隐藏，点击或移动唤出
- 外部阅读器支持 **上下滚动 / 左右翻页** 模式切换、省流/高清切换、服务端续读
- 本地阅读器显示作品名与章节名、页级改编动画入口

## 3. 过程中修复的三个问题

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 浮层里漫画页全黑 | 7 万像素高的 fixed 滚动容器导致位图不合成 | 改为文档流滚动（隐藏导航） |
| 续读定位失效、页码乱跳 | 滚动容器是 `.reader-full` 而代码监听 `window` | 统一用窗口滚动与 `window.scrollY` 计算 |
| 续读停在空白处 | 懒加载图片在视口外高度为 0，滚不到目标页 | 续读/跳页时强制预加载到目标页 |

另：页图改走**同源图片代理**（带磁盘缓存），避免跨域 CDN 在特定容器下的渲染问题，也提升稳定性。

## 4. 已知限制

1. 页图经服务端代理，流量计在服务器（个人自托管可接受；如需零带宽可改回直连）。
2. 左右翻页模式没有滑动/预加载优化（仅点击左右区域与方向键）。
3. 本地阅读器仍是分页窗口（5 页/窗口），未做条漫连续滚动。
4. 阅读器无亮度/背景色调节（B 站有）。
