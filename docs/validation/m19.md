# M19 验证记录：点进作品直达播放页 + 测试数据清理

> 日期：2026-11-09 · 变更：implement-play-direct（已归档）

## 1. 点进作品直达播放（对齐参考站）

问题：从首页/番剧索引/榜单点进动画作品，落到的是「作品详情 + 章节 + 外部源管理」，
与参考站「点开就是播放页」不一致。

实现：
- 新增 `GET /api/v1/works/{id}/play-target`：优先用**上次观看的集与线路**
  （`external_watch_progress`），否则首集；仅对有外部集的作品返回。
- 作品详情页：当 `chapters.length === 0` 且存在 play-target 时，
  `navigate(watchUrl, { replace: true })`，用户不再看到中间页。
- 含漫画章节的作品仍保留详情页（避免破坏阅读入口）。

验证：访问 `/works/ca1ced3e…`（尼古喵喵）自动跳到
`/works/…/external/46242c8c…`（第 1 话），播放页正常渲染。

## 4. 补记（2026-11-09）：「首页没改」修正

首版只改了 `/works/:id` 的跳转，但首页卡片走的是 `/catalog/:id`（目录详情），所以
从首页点进去仍然是详情页。修正为：

- 首页「最近更新」卡片：**已入库** → 直达 `/works/{workId}`（作品页再跳播放页）；
  **未入库** → 先物化（`POST /catalog-items/{id}/materialize`）再跳作品页。
- 首页「本季新番」横滚 / 时刻表预览：已入库条目同样直达作品页。
- 实测：首页点第一张卡片 → 自动物化 48 集 → 直接落在播放页（截图确认）。

取舍：卡片点击会为未入库条目创建一个作品（数据模型要求外部集挂在 work 上），
因此「只是浏览」也会写入我的作品。可接受，但需注意；后续可加「浏览态播放」的
不落库方案（把集绑定到 catalog item 而非 work）。
