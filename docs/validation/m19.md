# M19 验证记录：点进作品直达播放页 + 测试数据清理

> 日期：2026-11-09 · 变更：implement-play-direct（已归档）

## 1. 点进作品直达播放（对齐参考站）

问题：从首页/番剧索引/榜单点进动画作品，落到的是「作品详情 + 章节 + 外部源管理」，
与参考站「点开就是播放页」不一致。

实现：
- 新增 `GET /api/v1/works/{id}/play-target`：优先用**上次观看的集与线路**
  （`external_watch_progress`），否则首集；仅对有外部集的作品返回。
- 作品详情页：当 `chapters.length === 0` 且存在 play-target 时，
  `navigate(watchUrl, { replace: true })`，用户不再看到中间页。
- 含漫画章节的作品仍保留详情页（避免破坏阅读入口）。

验证：访问 `/works/ca1ced3e…`（尼古喵喵）自动跳到
`/works/…/external/46242c8c…`（第 1 话），播放页正常渲染。

## 2. 测试数据清理

→ works → 多余源 → upload_sessions/assets（仅删无引用）→ 归属转 admin → users。
