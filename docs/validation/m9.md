## 2. 过程中修复

| 缺陷 | 根因 | 修复 |
| --- | --- | --- |
| 日历接口 500（游标位置错误） | ResultSetExtractor 中 do/while 先读后移动游标 | 改 while (rs.next()) |
| 日历接口 500（numeric→Double） | PG numeric 不支持 getObject(Double.class) | getBigDecimal + doubleValue |
| 日历 148 > 114 | 一条 subject 匹配多条目录条目 → LEFT JOIN 扇出 | DISTINCT ON (subject_id) + 二次排序 |
| 封面不显示 | lain.bgm.tv 本机直连 000（代理 301→https） | 服务端封面代理 + http→https 归一化 |

## 3. 已知限制

1. 标题匹配为启发式（等值→前缀），覆盖率 29/114；未匹配的新番显示「资源未收录」。
   后续可用 Bangumi 别名/v0 搜索 API 提升。
2. 只缓存本季日历（in_calendar），历史季度不富化。
3. 封面尺寸为 Bangumi `common`（约 150px），大卡上略糊；可换 large 并做本地缓存。
4. Bangumi接口在受限网络需 `MANGASHELF_BANGUMI_PROXY`（本机 Clash 7892）。
5. 未做时刻表周视图、弹幕、Bangumi 账号绑定。
