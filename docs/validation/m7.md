## 1. 架构（gugu.fan 模式复刻）

解析与播放分离：Worker 无头浏览器嗅探直链（短时效 token，按次签发）→
前端 hls.js 直连源站 CDN（不经平台服务器）→ 失效自动重解析续播。
服务器只出 HTML/JSON，视频字节零带宽。

### 3.1 补测（2026-11-08 晚）：资源站 API 直连路线（M8 方向）

绕开前台站防御层，直连其上游**采集资源站 API**（MacCMS 开放接口，站长生态）实测：

| 项 | 结果 |
| --- | --- |
| 量子资源 API（cj.lziapi.com） | ✅ 搜索/详情 JSON 开放，斗罗大陆 265 集，`lzm3u8` 线路**直出 m3u8 直链** |
| 直链 CDN（vip.lz-cdn4.com） | ✅ 无 Referer + `ACAO: *`，curl 200（master→1200k 二级 playlist） |
| resolve 直链快路径 | ✅ 已实现：episode_url 本身是 m3u8/mp4 时免嗅探直接返回 |
| 本机浏览器验证 | ✗ 两头堵：WebKit 走系统代理（Clash 出口 404）；无头 Chromium 被指纹拒（404） |
| 结论 | 真实部署环境/加了直连规则的浏览器可播——`DOMAIN-SUFFIX,lz-cdn4.com,DIRECT` 即可解锁 |

采集 CDN 本体（sskan01/ppvod）实测**无 Referer 校验、CORS 全开**（M6/m6 遗留结论），
浏览器直连播放路径成立——瓶颈在"源站页面→直链"这步的自动化敌意防御。

## 4. 已知限制与后续路线

1. **登录墙源**：解析时注入用户提供的站点 Cookie 即可覆盖（gugu.fan 类），后续加
   规则源级 cookie 配置。
2. **WAF 指纹源**：无头浏览器被 TLS 指纹封锁（hhplayer 类）→ 正确兜底是
   "跳转原站"（已实现）与未来的浏览器扩展直连路线（用户真实浏览器天然过 WAF）。
3. **反自动化播放器**（webdriver 检测）：同上，扩展路线覆盖。
4. 外部集观看进度存 localStorage（客户端），服务端进度体系待与动画统一。
5. 解析期间 Worker 内存瞬时 +~300MB（Chromium），完成即释放；镜像 +~500MB。
6. yt-dlp 对目标生态实测无效（Unsupported URL），未纳入解析路径。
