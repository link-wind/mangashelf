## 2. 实现要点

- **播放器**（`web/src/components/Player.tsx`）：HLS（hls.js）/ MP4，控制条自动隐藏，
  进度条含缓冲显示，倍速轮换 1→1.25→1.5→2→0.75→0.5，静音不单独做（系统控制）。
- **弹幕**：`danmaku` 表（work_id+ordinal+time_ms，内容 1–200 字，颜色 #RRGGBB），
  7 条轨道按占用时间分配，seek 回退时重置游标与图层。
- **Banner**：`/api/v1/calendar` 评分降序前 5，6.5 秒轮播；背景用同一封面放大模糊。

## 3. 已知限制

1. 弹弹play 公开 API 需 AppId（实测 403），当前为**站内弹幕**；外部弹幕源待配置项接入。
2. 弹幕仅滚动模式（无顶部/底部固定、无屏蔽词与举报）。
3. 弹幕无防刷限流（单用户自托管；公开部署前需加）。
4. 自托管 `Watch` 页仍用原生控制条（未迁移到 Player 组件）。
5. 真实资源站 CDN 在本机部分线路被拦（v.lzcdn31.com status 0），播放器链路以本地流验证。
