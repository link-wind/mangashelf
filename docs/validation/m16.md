# M16 验证记录：外部漫画（MangaDex）

> 日期：2026-11-09 · 变更：implement-external-manga（已归档）
> 结论：接入 MangaDex 开放 API——搜索、详情（章节列表 + 语言过滤）、竖向滚动阅读器、
> 图片代理（白名单 + 磁盘缓存 + 限流）全部跑通，实测可读 One Piece 第 1 话 53 页。

## 1. 链路验证

| 环节 | 实测 |
| --- | --- |
| MangaDex API 可达性 | 直连 200（0.64s）；**代理反而不通**（本机 Clash 规则） |
| 搜索 | `/search?lang=zh` 返回 24 条；`lang=all` 可搜英文原名 |
| 详情 | One Piece：500 章（451 章 MangaDex 托管、其余为外部链接） |
| 章节页图 | `/at-home/server/{id}` → 53 页；dataSaver 117KB/2.1s，原图 900KB/19s |
| 图片代理 | 白名单（uploads.mangadex.org + *.mangadex.network）+ 磁盘缓存 + 并发 3 + 429 退避 |
| 阅读器 | 竖向滚动、懒加载、省流/高清切换、页序本地记录 |
| 封面 | 走代理加载（512px），冷启动受 MangaDex 限流影响较慢，缓存后秒开 |

## 2. 页面

- `/manga-ext`：搜索（中文 / English / 全部）+ 封面卡网格。
- `/manga-ext/:id`：封面、简介、年份/状态/语言、章节列表（语言切换、页数、外链章节说明）。
- `/manga-ext/read/:chapterId`：竖向阅读器 + 章节返回 + 省流模式。
- `/manga` 顶部增加「外部漫画（MangaDex）→」入口。

## 3. 已知限制

1. MangaDex 中文托管章节少（大量作品只有 en/es 等），界面已提示可切换语言；
   部分章节是「外链到官方站」，无法阅读（明确提示，不静默失败）。
2. 页图直连 CDN，本机首次加载较慢（2s/页）；失败自动回退服务端代理。
3. 无章节间「上一话/下一话」跳转（需回章节列表）。
4. 阅读进度仅本地记录，未与服务端书架/进度体系打通。
5. 未做下载/离线、评论、冷门语言兜底。
