## 实施发现

- **导航键过期闭包 bug**：初版把键盘 effect 依赖数组不含 page/isRestored，注册的处理器捕获
  注册时的旧状态导致按键永不起效（真实按键与合成事件均复现）。改为 navRef 每渲染写入最新值、
  effect 空依赖注册一次。
- **RTL 双重取反 bug**：onNavKey 已按 RTL 反转 delta，flip 内又反转一次 → RTL 下方向错。
  统一为「flip(delta>0)=阅读方向前进，flip 内部按 dir 反转」，调用方传原始语义。
- 腾讯/拷贝源在本机无代理环境下搜索失败（上游限制），显式报错符合规格；MangaDex/哔哩正常。
