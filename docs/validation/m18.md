# M18 验证记录：跨源桥接与漫画进度服务端化

> 日期：2026-11-09 · 变更：implement-manga-bridge（已归档）
> 结论：哔哩漫画热门榜的条目可用中文标题在 MangaDex 找到同作（实测 10/12 命中），
> 命中后提供「站内读」；外部漫画阅读进度改为服务端保存，并入观看历史。

## 1. 跨源桥接

**关键实测**：MangaDex 的 `title` 检索本身是跨语言的——中文「航海王」可命中 One Piece、
「间谍过家家」命中 SPY×FAMILY、「碧蓝之海」命中 Grand Blue。但返回体不一定带中文别名，
因此不能只靠字面相似度判定。

匹配策略（三级）：
1. 任一标题/别名归一化后完全相等 → 命中；
2. 二元组相似度 ≥ 0.72 → 命中；
3. 检索有结果且标题长度 ≥ 2 → 取首位（MangaDex 相关性排序），界面按「站内」展示。

结果：哔哩漫画热门前 12 条命中 **10 条**（未命中：是师姐我们有救了、香格里拉边境）。
匹配结果按标题缓存 1 小时；仅对前 12 条做匹配（首次约 7s，之后走缓存）。

## 2. 进度服务端化（V13）

```sql
CREATE TABLE external_manga_progress (
  user_id, source, manga_id, chapter_id, chapter_label,
  page, total_pages, title, cover_url, updated_at,
  PRIMARY KEY (user_id, source, manga_id)
);
```

- `PUT /api/v1/me/manga-progress`：滚动时节流 3 秒上报，离开页面时再报一次。
- `GET /api/v1/me/manga-progress`：续读与历史列表。
- 阅读器进入时优先取服务端进度（同章且 page>1）滚到对应页，localStorage 兜底。
- 观看历史页新增「漫画阅读」分区（标题 / 第几话 / 第几页 / 总页数 / 源）。

## 3. 界面变化

- 热门榜卡片：命中跨源的条目不再标「站外」，点击进入站内 MangaDex 详情并可在站内读；
  未命中的仍跳哔哩漫画原页。
- 历史页：漫画阅读与动画观看并列，均可一键继续。

## 4. 已知限制

1. 第 3 级「取检索首位」是启发式：极少数同名/近似作品可能误配（界面标为「站内」，
   进入后可看到实际标题再判断）。
2. 跨源匹配不做章节级对齐（MangaDex 章号与哔哩漫画章号不保证一致），进度按
   MangaDex 章节记录。
3. 进度表按 (user, source, manga_id) 存一条，只保留最近阅读的章节。
4. 未做「读完后自动跳下一话」。
