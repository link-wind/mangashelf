# web-ui Specification

## Purpose
站点级 Web UI 要求：页面在移动端视口可用、关键交互一致；与具体业务能力分离。

## Requirements

### Requirement: 移动端响应式布局

站点页面 MUST 在移动端视口（≥360px 宽）下可用：顶部导航与搜索可换行收纳，内容网格
MUST 按视口宽度自适应列数，详情/播放双栏布局 MUST 折叠为单栏，阅读器控件 MUST 不遮挡
正文。禁止横向滚动（阅读器画布内容自身除外）。

#### Scenario: 手机打开首页与索引

- **WHEN** 用户以 390px 宽视口打开首页、番剧索引、漫画相关页
- **THEN** 无横向滚动，网格列数自适应，导航与搜索完整可见

#### Scenario: 手机阅读与播放

- **WHEN** 用户以手机视口进入阅读器或播放页
- **THEN** 双栏布局折叠为单栏，翻页/设置控件可用且不遮挡正文

### Requirement: 手机端悬浮导航菜单

移动端视口（≤720px）下顶部导航链接与次级操作 MUST 收纳：顶栏仅保留品牌标识与必要入口，不得与悬浮菜单重复渲染设置、退出或主题切换按钮；右下角显示液态玻璃悬浮按钮，点击展开导航菜单（含全部页面入口、站内搜索入口、主题切换、设置与退出）；菜单展开时 MUST NOT 丢失当前页面，再次点击遮罩、按钮或选择入口后收起。桌面视口 MUST NOT 出现悬浮按钮。

#### Scenario: 手机展开导航

- **WHEN** 用户以 390px 宽视口访问首页并点击右下角悬浮按钮
- **THEN** 展开包含首页、漫画、索引、时刻表、搜索、收藏、历史、主题切换、设置与退出的玻璃菜单，顶栏无重复设置/退出按钮；点击「搜索」跳转到 `/search` 并自动收起菜单

#### Scenario: 桌面不受影响

- **WHEN** 桌面视口（>720px）访问站点
- **THEN** 顶部导航正常显示（用户设置/素材/退出收纳在头像下拉菜单内），无右下角悬浮按钮

### Requirement: 液态玻璃浮层与内容分层

站点浮层与导航控件（顶栏、Hero Banner 悬浮控件与缩略图托盘、阅读器与播放器浮动控制栏及目录抽屉、手机端悬浮菜单、下拉菜单、Toast 提示、登录卡）MUST 采用明暗双主题适配的液态玻璃材质（半透明背景模糊、高光描边与柔和投影）；大面积列表卡片与表单正文 MUST 保持实体背景以确保文字对比度与滚动流畅度，并在不支持 `backdrop-filter` 或开启 `prefers-reduced-transparency` 时优雅回退为可读实底。

#### Scenario: 明暗双主题下的浮层可读性

- **WHEN** 用户在亮色与暗色主题间切换并浏览首页、登录页、阅读器与播放器
- **THEN** 所有液态玻璃浮层上的文字、图标与按钮保持清晰可读，不出现低对比度或遮挡正文问题

### Requirement: 主题无闪烁初始化与页面标识

站点 MUST 在页面首帧渲染前应用已保存的主题偏好（无保存记录时跟随系统 `prefers-color-scheme`），暗色模式下刷新页面 MUST NOT 出现白屏闪烁；站点 MUST 提供自定义 Favicon 并随当前路由更新浏览器标签页标题。

#### Scenario: 暗色模式刷新页面

- **WHEN** 已选择暗色主题的用户刷新任意页面
- **THEN** 文档根节点在首帧前即带有 `data-theme="dark"`，页面背景直接呈现暗色

### Requirement: 统一封面兜底、加载骨架与操作反馈

全站作品/番剧/漫画封面 MUST 具备统一的加载与失败兜底表现（封面缺失或加载失败时展示渐变首字占位，不得塌陷或显示空白灰块）；首页首屏加载期间 MUST 展示等比例骨架屏以减少布局抖动；收藏、取消收藏、复制凭证等主动操作 MUST 提供轻量 Toast 反馈，且错误场景显式提示、不静默吞错。

#### Scenario: 封面加载失败兜底

- **WHEN** 任意卡片或继续观看/阅读条目的封面 URL 缺失或返回 404
- **THEN** 封面容器保持 `3:4` 比例并展示可读的首字占位，不出现破图图标或纯空灰块

#### Scenario: 全局搜索显式展示全类别结果与错误

- **WHEN** 用户在 `/search` 输入关键词检索
- **THEN** 并行展示番剧目录、外部漫画目录与站内标题/对白命中；任一目录检索失败时显式提示错误，仅当所有类别均无命中时才显示空态文案

### Requirement: 访客浏览公开内容

未登录访客 MUST 能够浏览、阅读、观看并检索站点公开（`PUBLIC` 且 `PUBLISHED`）内容，与 DESIGN 第 3.1/3.2 节一致；私有内容（书架、观看/阅读进度、我的素材、设置、令牌、上传与所有写操作）MUST 要求登录。访客对受保护资源的未认证访问 MUST 返回 401（而非伪装成 403 或空响应），前端在访客触发写操作或访问私有页面时 MUST 引导至登录页并在登录后回到原页面。

#### Scenario: 访客浏览公开内容

- **WHEN** 未登录用户访问首页、番剧索引、漫画专区、目录详情或执行站内搜索
- **THEN** 页面与公开内容正常渲染，仅召回 `PUBLIC` 且 `PUBLISHED` 的条目；顶栏显示「登录」入口而非用户菜单

#### Scenario: 访客访问私有页面被引导登录

- **WHEN** 未登录用户打开 `/shelf`、`/settings` 或 `/history`，或点击「收藏」
- **THEN** 跳转到 `/login?next=<原路径>`；登录成功后回到原路径；`next` 只接受站内相对路径以防止开放重定向

#### Scenario: 访客只读边界

- **WHEN** 未登录用户请求 `/api/v1/me/**`、`/api/v1/uploads` 或 `/api/v1/admin/**`
- **THEN** 返回 401 `UNAUTHENTICATED` 统一错误结构；请求公开只读端点返回 200 且不含私有数据
