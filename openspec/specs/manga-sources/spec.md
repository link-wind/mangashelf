# manga-sources Specification

## Purpose
管理中文漫画来源的发现、章节目录、站内阅读入口和阅读进度，使作品按明确声明的源能力进入统一界面；哔哩公开免费章节的完整阅读与按原来源续读也由本能力约束。

## Requirements

### Requirement: 漫画数据源可插拔

平台 MUST 以统一接口描述漫画数据源及其能力，新增源不改动统一入口。

#### Scenario: 能力缺失

- **WHEN** 客户端请求某源不支持的接口（如哔哩漫画的搜索）
- **THEN** 返回 409 SOURCE_CAPABILITY_UNAVAILABLE 并说明原因

### Requirement: 热门榜元数据

漫画页 MUST 展示至少一个数据源的热门榜，并标明条目是否可站内阅读。

#### Scenario: 切换榜单源

- **WHEN** 用户在漫画页切换数据源
- **THEN** 榜单按该源排序展示；不可站内阅读的条目跳转官方页面

### Requirement: 哔哩公开章节完整阅读

平台 MUST 只为无需登录或付费即可阅读的哔哩章节提供按原顺序排列的站内页图。确认完整索引后 MUST 返回全部页位和站内读取地址，图片按用户阅读位置加载，不以浏览器逐页截图作为正常阅读路径。页图读取 MUST 验证当前登录会话并禁止共享缓存；清单就绪不代表全部页图已经下载成功。

#### Scenario: 已知公开章节

- **WHEN** 已登录用户打开已知的哔哩公开章节
- **THEN** 阅读器显示完整页数，只加载阅读位置附近图片，用户可直接跳到末页而无需等待整章下载

#### Scenario: 页数未知或部分页面未就绪

- **WHEN** 无法确认完整索引，或某页下载、格式、尺寸校验失败
- **THEN** 返回明确错误；图片失败显示页级提示和重试操作，不把未加载页伪装成已加载

#### Scenario: 上游限制访问

- **WHEN** 上游要求登录、购买或解锁
- **THEN** 停止读取并说明不可读，不使用个人登录态或截图回退

#### Scenario: 未就绪页图被读取

- **WHEN** 客户端读取尚未缓存的合法页位
- **THEN** 服务端只下载并校验该页，成功后返回图片，失败明确报错，响应禁止共享缓存

#### Scenario: 续读不下载章首

- **WHEN** 用户从历史恢复到章节后部
- **THEN** 优先加载保存位置附近页图，保持完整页序和当前位置，不先下载整章或章首图片

### Requirement: 哔哩榜单进入站内章节目录

哔哩榜单 MUST 进入站内详情。仅在能够核对官方章节清单完整性时展示站内目录；明确免费且未锁定的章节可在站内打开，其他章节提供原站入口。

#### Scenario: 公开目录可用

- **WHEN** 用户选择能获取完整章节列表的哔哩榜单条目
- **THEN** 打开该作品的站内详情，用户可选择公开章节阅读，也可切换到全部章节

#### Scenario: 章节列表不可用

- **WHEN** 作品无法可靠取得章节列表
- **THEN** 告知用户当前无法取得站内目录并提供原站入口

#### Scenario: 章节锁定

- **WHEN** 用户查看完整目录中的锁定章节
- **THEN** 该章节提供原站入口，不标记为站内可读

### Requirement: 外部漫画进度服务端保存

外部漫画阅读进度 MUST 保存在服务端并可在历史中按原来源、作品、章节及页码续读。
进度写入 MUST 携带 `expectedVersion`，版本冲突时返回 409 `PROGRESS_CONFLICT` 与当前快照，
MUST NOT 覆盖已保存位置；进度列表 MUST 返回 `version` 供客户端续读时携带。

#### Scenario: 跨设备续读

- **WHEN** 用户从历史打开同一作品的同一章节
- **THEN** 阅读器按记录中的漫画源请求页图并恢复上次页码；历史页展示「第 X 话 第 N 页」

#### Scenario: 多设备过期写入

- **WHEN** 两台设备以同一 `expectedVersion` 保存同一作品进度
- **THEN** 后到者收到 409 与当前快照；阅读器以服务端版本更新本地状态并显式提示，不静默覆盖

### Requirement: 全能力中文漫画源

平台 MUST 提供至少一个支持榜单/搜索/详情/站内阅读的中文漫画数据源。

#### Scenario: 中文关键词搜索命中正版源

- **WHEN** 用户在搜索页选择腾讯动漫并输入中文标题
- **THEN** 返回该源匹配条目（标题与作者），可进入站内详情

#### Scenario: 免费章节站内阅读

- **WHEN** 用户从详情页打开免费章节
- **THEN** 阅读器加载该话全部页图并可翻页、保存进度

#### Scenario: 付费章节显式失败

- **WHEN** 用户打开付费或不可读章节
- **THEN** 返回明确错误说明，不展示空阅读器也不静默跳转

### Requirement: 外部漫画按源路由

外部漫画详情与阅读 MUST 支持按源分发；所有源（含 MangaDex）MUST 经统一的
manga-sources 接口提供详情、章节与页图，旧聚合端点在调用迁移后退役。
缺省源保持既有行为。

#### Scenario: 旧链接兼容

- **WHEN** 打开不带 source 参数的外部漫画详情/阅读链接
- **THEN** 按 MangaDex 处理（与历史进度兼容）

#### Scenario: MangaDex 走统一接口

- **WHEN** 前端打开 MangaDex 作品详情或章节页图
- **THEN** 与规则源使用同一 manga-sources 响应协议，不再调用旧聚合端点

### Requirement: 漫画首页发现流

漫画首页 MUST 展示至少一个数据源的推荐/榜单分区，并支持源切换。

#### Scenario: 首页展示多分区

- **WHEN** 用户打开漫画首页并选择腾讯动漫
- **THEN** 依次展示编辑推荐、飙升榜、畅销榜、新作榜、真香榜等分区，每区可横向浏览并进入详情

#### Scenario: 分区内打开作品

- **WHEN** 用户点击任一分区中的作品
- **THEN** 进入该源的站内详情页，可继续阅读

#### Scenario: 无多分区的源

- **WHEN** 用户切换到只有单榜单的源（哔哩漫画/MangaDex）
- **THEN** 页面以单个「热门」分区展示，不报错

#### Scenario: 发现流不可用

- **WHEN** 所选源接口失败或上游改版
- **THEN** 页面显示明确错误，本地漫画区块仍可正常使用

### Requirement: 多源聚合推荐

漫画首页 MUST 提供跨中文数据源的聚合推荐，且不展示非中文源或非中文标题内容。

#### Scenario: 综合榜融合多源

- **WHEN** 用户打开漫画首页并选择「综合」
- **THEN** 展示综合热榜（多源作品按融合得分排序、同作只出现一次）以及各中文源的原始分区

#### Scenario: 非中文源被排除

- **WHEN** 某个数据源声明为非中文（如 MangaDex）
- **THEN** 该源不参与聚合推荐，也不出现在漫画首页的源切换中

#### Scenario: 非中文内容被过滤

- **WHEN** 聚合结果中出现纯非中文标题
- **THEN** 该条目不出现在综合榜中

#### Scenario: 单源失败

- **WHEN** 某个中文源请求失败或超时
- **THEN** 其余源正常展示，页面以提示说明失败源，不整体报错

### Requirement: 跨源同作合并

聚合推荐 MUST 将同一作品在不同源/不同榜单的条目合并为单个卡片，并标明可读源数量。

#### Scenario: 同作跨源只出现一次

- **WHEN** 同一作品同时出现在两个中文源的榜单中
- **THEN** 综合热榜只显示一张卡，标注「2 源」，点击进入最可读的源

#### Scenario: 不同版本不误合并

- **WHEN** 两部作品标题仅版本后缀不同（如「全彩版」「番外篇」）
- **THEN** 它们作为不同作品分别展示

#### Scenario: 无可读版本

- **WHEN** 合并后的作品在中文源均不可站内阅读
- **THEN** 卡片标注站外，点击打开对应源官方页面

### Requirement: 拷贝漫画 HTTP 章节目录

平台 MUST 在不启动浏览器的情况下通过拷贝漫画官方 v3 匿名 API 读取公开详情和完整
章节目录，保持既有章节标识与官网顺序。平台 MUST 复用有效的有界目录缓存；目录
无效、缺失或上游失败时明确报错，不自动回退浏览器或返回不完整列表。目录读取 MUST
不依赖个人登录态。

#### Scenario: 首次打开详情

- **WHEN** 用户打开尚未缓存的拷贝漫画作品
- **THEN** 通过 v3 API 获取详情与完整目录，按分组和分页读取全部章节，不启动 Python 或浏览器

#### Scenario: 重复与并发打开详情

- **WHEN** 多个请求同时读取同一作品或读取有效缓存
- **THEN** 复用同一份成功结果，避免重复抓取；缓存有明确过期与容量边界

#### Scenario: 目录不完整或接口变化

- **WHEN** 目录声明数量与实际章节不符、分页截断、章节重复、UUID 非法或上游不可用
- **THEN** 返回明确错误，不把部分目录标为成功，不启动浏览器兜底

#### Scenario: 原有章节仍可打开

- **WHEN** 用户从 v3 目录打开章节或从历史记录继续阅读
- **THEN** 使用既有章节 ID 和 v3 章节图片接口，阅读器按需加载页图

### Requirement: 拷贝漫画 HTTP 章节图片

平台 MUST 在不启动浏览器的情况下通过拷贝漫画官方 v3 匿名章节接口读取公开章节的
完整页图清单，保持上游页序。平台 MUST 使用 `chapter.size` 校验
`chapter.contents` 数量；声明页数与实际图片数不一致时 MUST 返回明确错误，不得
把不完整章节标为成功或写入成功缓存。成功清单 MUST 有明确的缓存过期与容量边界。
受限章节 MUST 返回登录提示，不伪造页图。

#### Scenario: 打开公开章节

- **WHEN** 用户打开匿名可读的拷贝漫画章节
- **THEN** 通过 v3 章节接口返回 `size` 张页图，不启动 Python 或 Chromium

#### Scenario: 声明页数与实际内容不一致

- **WHEN** 章节声明 `size=10` 但接口只返回 1 个或 9 个 `contents`
- **THEN** 返回 502 `COPYMANGA_READER_INVALID`，阅读器不显示不完整章节

#### Scenario: 上游限流或受限章节

- **WHEN** 上游返回 `code=210`
- **THEN** 返回 502 `COPYMANGA_READER_RATE_LIMITED`，不把限流表述为登录失败
- **WHEN** 章节 `is_lock=true` 且没有可用页图
- **THEN** 返回 403 `COPYMANGA_LOGIN_REQUIRED`，提示配置登录态

### Requirement: 浏览器解析的漫画源

平台 MUST 支持通过无头浏览器执行源站 JS 获得章节页图，用于纯 HTTP 无法解析的源。
浏览器解析任务 MUST 由 Worker 角色执行，API 角色 MUST NOT 运行 Chromium；
无 Worker 消费解析队列时 MUST 显式提示解析不可用，其他数据源与首页基础功能
MUST NOT 受影响。公开拷贝漫画章节 MUST NOT 把浏览器作为正常阅读路径；只有章节
明确要求登录且已配置登录态时，才允许回退浏览器。

#### Scenario: 站内阅读纯浏览器源

- **WHEN** 用户打开只能由浏览器解析的源章节
- **THEN** Worker 执行 Playwright 解析出页图 URL，阅读器可按需加载，API 进程内无浏览器实例

#### Scenario: 站内阅读公开拷贝漫画章节

- **WHEN** 用户从拷贝漫画详情页打开公开章节
- **THEN** 服务端通过 v3 HTTP 接口返回完整页图，不启动浏览器

#### Scenario: 需要登录的章节

- **WHEN** 章节内容仅登录可见且已配置登录态
- **THEN** 允许浏览器回退；未配置登录态时返回明确错误，不展示空阅读器

#### Scenario: 只允许站内 URL

- **WHEN** 解析请求携带非 copy4000.com 的 URL
- **THEN** Python 任务拒绝执行

#### Scenario: 纯 API 部署下的浏览器源

- **WHEN** 仅部署 API 而无 Worker 消费解析队列时访问浏览器型数据源
- **THEN** 该源明确返回解析不可用，漫画首页与 HTTP 数据源仍正常

### Requirement: 详情页切换数据源

外部漫画详情页 MUST 允许用户按标题在其它中文数据源查找同作并跳转。

#### Scenario: 从腾讯动漫切到拷贝漫画

- **WHEN** 用户在腾讯动漫某作品详情页点击「拷贝漫画」
- **THEN** 按作品标题搜索拷贝漫画并列出结果，点击结果进入拷贝漫画详情

#### Scenario: 当前源不出现

- **WHEN** 详情页收集可切换源
- **THEN** 排除当前源与非中文/不支持搜索的源，不显示无意义的自切换

### Requirement: 浏览器源声明式接入

平台 MUST 支持通过规则（URL 模板 + 选择器）声明浏览器漫画源，新增站点不改
Java 代码。

#### Scenario: 新增包子漫画源

- **WHEN** 启用包含 browserPlan 的规则行
- **THEN** 该源自动注册，支持搜索、详情与站内阅读

#### Scenario: 统一展开展示

- **WHEN** 用户打开任意浏览器源的作品
- **THEN** 详情与阅读器使用站内统一 UI，仅数据提取按规则执行

#### Scenario: 页图多 CDN 去重

- **WHEN** 同一页图出现在多个 CDN 域名
- **THEN** 按 URL 路径去重，阅读器不重复显示

### Requirement: 浏览器源支持分页章节接口

浏览器规则源 MUST 支持通过公开分页 API 获取章节列表。

#### Scenario: 自动翻页

- **WHEN** 规则配置 `chaptersApi` 且接口返回 `total_pages > 1`
- **THEN** 服务端按规定页大小逐页拉取并合并为完整章节列表

#### Scenario: 章节标识通用化

- **WHEN** 章节接口返回站点自有 ID（如 hid）
- **THEN** 阅读页直接以该 ID 构造 URL，不再强制要求 `{mangaId}|{slot}`

### Requirement: 漫画首页与源解析缓存

平台 MUST 缓存各源分区与浏览器解析结果，避免重复抓取造成首页/切换/阅读等待。
分区与发现流缓存 MUST 经 Redis 跨实例共享（键含源、资源、语言与规则版本）；
浏览器解析结果维持磁盘缓存（服务重启后仍可复用）。Redis 不可用时 MUST 降级为
实例内缓存并明确告警计数，MUST NOT 影响业务正确性；缓存键 MUST NOT 包含原始
Cookie 或登录态。

#### Scenario: 重复打开首页

- **WHEN** 用户在 10 分钟内再次打开漫画首页或切换到已加载过的源（任意实例）
- **THEN** 直接使用共享缓存内容渲染，后台按需刷新

#### Scenario: 浏览器源重复阅读

- **WHEN** 用户再次打开同一浏览器源章节（含服务重启后）
- **THEN** 从磁盘缓存返回页图列表，不再启动浏览器解析

#### Scenario: Redis 不可用降级

- **WHEN** Redis 连接失败或超时
- **THEN** 首页与详情按实例内缓存或直接回源返回，错误计数告警，业务不中断

### Requirement: 哔哩页图持久缓存

平台 MUST 复用有效的哔哩目录、索引和已下载图片缓存，缓存 MUST 有明确的过期与容量边界，且服务重启后仍能复用。签名 URL、匿名指纹和个人登录态 MUST 不持久保存。

#### Scenario: 同页重复和并发请求

- **WHEN** 相同合法页位被重复或并发读取
- **THEN** 复用有效图片或同一次下载结果，不重复下载整章，也不暴露部分写入文件

#### Scenario: 服务重启后读取

- **WHEN** 服务重启后读取仍有效且章节仍可访问的缓存页
- **THEN** 复用磁盘图片，不重新下载该页

#### Scenario: 过期或容量不足

- **WHEN** 缓存过期、索引版本变化或达到容量上限
- **THEN** 重新核对合法索引并按需获取，过期或最旧缓存被清理，上游失败时不以过期授权静默交付

### Requirement: 外部漫画与条漫按需加载

所有外部漫画来源的阅读器 MUST 按阅读位置请求正文图片，包括竖向长条漫画；恢复进度前
MUST 不请求正文，不为判断条漫而额外预读章首。已确认的页序 MUST 保持完整，未加载和
失败页 MUST 有明确状态，图片失败 MUST 提供页级重试。

#### Scenario: 打开长条章节

- **WHEN** 用户打开包含多页长条图片的外部章节
- **THEN** 只请求视口附近页，其他页保持占位，不下载整章原图

#### Scenario: 续读章节后部

- **WHEN** 历史记录指向条漫章节后部
- **THEN** 恢复该页并只加载附近正文，不先取章首图片

#### Scenario: 图片尺寸后到

- **WHEN** 未提供尺寸的图片加载后改变前方页位高度
- **THEN** 当前阅读页保持在原视口位置，页码不因占位更新跳回前页

#### Scenario: 站内切换章节

- **WHEN** 用户进入下一话且其清单尚未返回
- **THEN** 展示该话加载状态，不使用上一话页图；确认新话清单和进度后按新位置加载

#### Scenario: 自动识别与手动切换

- **WHEN** 阅读中确认图片为条漫，或用户手动改变页模式
- **THEN** 自动滚动及手动模式均保留当前阅读位置，手动选择优先

#### Scenario: 双页阅读

- **WHEN** 用户使用双页或首页单排模式
- **THEN** 只请求当前页组和下一页组，切换模式与历史续读保持所在页

#### Scenario: 页图最终失败

- **WHEN** 图片直连及已支持的代理读取均失败
- **THEN** 显示该页失败原因和重试操作，不隐藏该页或将其标记为读取成功

### Requirement: 历史截图链接显式失效

哔哩历史截图阅读链接 MUST 返回明确的 410 提示，说明截图阅读已替换为 HTTP 页图，
MUST NOT 静默失败或恢复截图管线。

#### Scenario: 打开历史截图链接

- **WHEN** 用户访问历史哔哩截图会话或截图产物链接
- **THEN** 收到明确的 410 提示并引导使用 HTTP 页图阅读

### Requirement: 漫画源可选题材浏览

漫画数据源 MAY 提供题材（如热血/机甲/恋爱）浏览能力：声明题材清单并支持按题材
获取作品列表。声明了题材的源 MUST 在漫画索引页展示题材 tab；未声明的源 MUST 隐藏
题材 tab（不影响搜索与榜单）。

#### Scenario: 有题材能力的源按题材浏览

- **WHEN** 用户在漫画索引选择拷贝漫画源的「热血」题材
- **THEN** 网格展示该题材下的作品，可进入详情阅读

#### Scenario: 无题材能力的源

- **WHEN** 用户切换到未声明题材能力的源
- **THEN** 题材 tab 隐藏，搜索与榜单功能不受影响

### Requirement: 漫画目录落库与同步

平台 MUST 维护漫画目录表（按源 + 源内标识唯一），支持周期性同步：支持全量遍历的源
（如拷贝漫画按题材分页）MUST 同步全量；仅有榜单/分区能力的源 MUST 把可见条目入库
（渐进式）。同步 MUST 限速执行；重复同步 MUST 按 (source, source_item_id) 幂等 upsert。
实时搜索命中条目 MUST 顺手入库。目录查询 MUST 支持题材（tags）、状态与标题搜索过滤，
题材清单 MUST 从库内 tags 聚合得出。

#### Scenario: 拷贝漫画全量同步

- **WHEN** 同步任务执行拷贝漫画源
- **THEN** 逐题材分页抓取并限速入库；重复执行条目数量不重复增长

#### Scenario: 渐进式入库

- **WHEN** 用户在漫画索引对无全量能力的源执行实时搜索并命中条目
- **THEN** 命中条目入库；再次打开索引时库内可见

#### Scenario: 题材聚合与筛选

- **WHEN** 用户打开漫画索引并选择某题材
- **THEN** 题材清单从库内 tags 聚合得出，筛选结果只含该题材条目

#### Scenario: 上游不可用不影响索引

- **WHEN** 某上游源不可达时用户浏览漫画索引
- **THEN** 库内目录正常展示，同步任务显式失败并可重试，页面不依赖上游


### Requirement: 全流漫画聚合搜索与源健康熔断

系统 MUST 提供全流漫画聚合搜索端点 `GET /api/v1/manga-discovery/search`，并发检索所有启用且支持搜索的中文在线源、本地 `manga_catalog_items` 目录库与当前用户有权访问的站内漫画作品。单源请求 MUST 具备共享总截止超时隔离与连续失败自动冷却机制，避免单一故障源拖慢或阻断其余流结果；跨流同作条目 MUST 基于归一化标题与相似度合并展示多源入口，并显式返回各流检索状态。

#### Scenario: 单源异常时全流搜索降级返回

- **WHEN** 用户执行全流漫画搜索且其中一个在线源超时或连接失败
- **THEN** 接口在超时窗口内返回其余正常流及目录库的去重合并结果，并在 `sourceStatus` 中标注异常源原因；连续失败达阈值后自动冷却跳过

### Requirement: 漫画发现与推荐打分优化

漫画发现聚合与推荐接口 `GET /api/v1/recommendations/manga` MUST 综合站内可读性加权、跨源共识加成与同作者多样性打散；登录用户请求推荐时 MUST 结合其收藏与阅读历史涉及的题材标签做个性化重排、排除已在读或已收藏作品，并附带可解释推荐理由与换一批偏移支持。

#### Scenario: 站内可读条目优先与多样性约束

- **WHEN** 多源热榜存在站内可读条目与纯外链条目，或同一作者连续占据多个名次
- **THEN** 站内可读条目获得优先权重，且推荐列表中同一作者不连续重复出现
