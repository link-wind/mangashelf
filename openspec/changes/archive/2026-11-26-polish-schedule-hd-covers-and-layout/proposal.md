# Proposal: 高清封面切档、统一 3:4 栅格与角标、新版时刻表及 P1 浏览/播放体验升级

## Why

对照业内优秀二次元站点（如 gugu.fan）的实测体验，MangaShelf 在视觉精细度与浏览效率上仍有 6 个可低成本大幅提升的环节：
1. **封面清晰度不足**：动画封面大量使用 `?size=common` / `?size=small`（在 2× Retina 屏被拉伸发虚），漫画列表页未统一提升腾讯/哔哩缩略图档位。
2. **卡片比例与列数不统一**：不同页面网格宽度与横滚卡片宽度不一致、长标题拉齐不一致、角标位置零散。
3. **新番时刻表信息密度与可读性弱**：7 列竖排挤压导致封面极小、无今日高亮、无简介、无法筛选“仅看可播/我的追番”。
4. **首页纵向堆叠偏长**：缺少 70/30 左网格 + 右多榜侧栏节奏及「完结补番精选」入口。
5. **索引页浏览效率待提升**：缺少「网格 / 列表」双视图切换、分页直达跳页输入框与多标签折叠。
6. **播放页与漫画章节列表缺长篇友好交互**：选集缺少正倒序、长篇集数区间分组、自动连播开关及侧栏相似推荐。

## What Changes

- **P0 视觉与时刻表**：全站动画封面切 `large` 档并更新预热逻辑；漫画列表封面提档并防裁头顶；统一 `1344px` 内容宽、固定 `3:4` 比例（7→5→4→2 响应式列数）与四角角标；全面重构 `/schedule`（KPI 态势卡 + 筛选胶囊 + 7 列今日高亮周历条 + 8:4 双栏 + 焦点/紧凑双档横卡 + 右侧重磅雷达与我的追更表）。
- **P1 首页、索引与播放增强**：首页升级 70/30 左推荐网格 + 右多 Tab 榜单卡、完结补番行与带计数题材探索；分页组件新增跳页直达；番剧/漫画索引新增网格/列表双视图与多题材折叠；顶栏/索引搜索框加一键清除；播放壳新增正倒序、长篇集数分段、自动连播开关与相似推荐接口 `GET /api/v1/recommendations/anime/{id}/similar`；漫画详情章节超 50 话自动分段。
