# web-ui Specification Delta

## ADDED Requirements

### Requirement: 全站高清封面与统一 3:4 栅格角标体系

动画（Bangumi）与漫画封面在网格、时刻表与侧栏 MUST 优先加载适配 Retina 向下采样的高清档位（Bangumi `large`、腾讯 `/0`、哔哩 `@600w`），配合持久化缓存避免重复回源；全站内容容器 MUST 统一最大宽 `1344px` 与 `3:4` 海报比例，桌面全宽网格采用 `7→5→4→2` 响应式列数、固定单行截断标题与统一四角角标。

#### Scenario: 卡片封面在 Retina 屏保持清晰与整齐
- **WHEN** 用户在桌面（1440px）与手机（390px）浏览首页、时刻表、番剧索引与漫画页
- **THEN** 所有海报严格维持 `3:4` 比例与高清源图，卡片行高一致、无人物头顶被裁切或长标题撑高错位

### Requirement: 新版交互式新番时刻表、索引双视图与选集分段

`/schedule` MUST 提供顶部本季统计 KPI、筛选胶囊（全部/仅可播/我的追番）、高亮当日的 7 天周历切换条，以及宽屏 8:4 双栏布局（左侧焦点横卡与双列紧凑横卡，右侧本周重磅雷达与我的追更表）。番剧与漫画索引 MUST 支持海报网格与双栏列表双视图切换及页码直达跳转；播放页选集与漫画长篇章节列表 MUST 支持正/倒序、自动分段与连播开关，播放页侧栏提供相似推荐。

#### Scenario: 切换时刻表星期与筛选
- **WHEN** 用户在 `/schedule` 点击任意星期或切换「仅看可播」
- **THEN** 主排期流与 URL `?day=` 同步更新，无页面刷新丢失状态
