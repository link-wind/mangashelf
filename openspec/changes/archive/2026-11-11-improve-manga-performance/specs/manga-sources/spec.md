# manga-sources 增量：分区与解析缓存

## ADDED Requirements

### Requirement: 漫画首页与源解析缓存

平台 MUST 缓存各源分区与浏览器解析结果，避免重复抓取造成首页/切换/阅读等待。

#### Scenario: 重复打开首页

- **WHEN** 用户在 10 分钟内再次打开漫画首页或切换到已加载过的源
- **THEN** 直接使用缓存内容渲染，后台按需刷新

#### Scenario: 浏览器源重复阅读

- **WHEN** 用户再次打开同一浏览器源章节（含服务重启后）
- **THEN** 从磁盘缓存返回页图列表，不再启动浏览器解析
