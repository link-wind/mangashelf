## Context

见 proposal.md。现有普通 Chromium 匿名阅读器可渲染公开章节，但前期旧形式接口探测返回通用错误，尚不能确定是参数、网络、上下文还是签名原因。DESIGN §19 禁止把 Cookie、Authorization 或签名 URL 写入日志。

## Goals / Non-Goals

**Goals:**

- 观察一章实际请求，区分目录、索引、令牌、页图与解码阶段。
- 将可用请求仅保留在内存中，以 HTTP 验证完整页图，图片逐张加载核验。
- 明确记录浏览器是否用于初始化、是否必须保持运行、是否执行了解码；不得把浏览器截图或浏览器内解码称为纯 HTTP。

**Non-Goals:**

- 不修改生产采集链路，不实现通用下载器或签名框架。
- 不使用个人登录态，不处理付费或锁定章节，不把公开图片提交到仓库。

## Decisions

- 样本固定为既有匿名公开章节《航海王》第 004 话；需要排除偶然性时补充另一公开章节。
- 观察阶段使用现有 Chromium 启动方式，禁止调用截图。HTTP 阶段使用标准库或独立 Playwright HTTP 客户端，必要的匿名上下文仅留内存。
- 输出只包含请求类别、HTTP 状态、业务状态、页数、图片格式、尺寸、摘要与耗时；不输出完整请求、响应正文、Cookie 或签名 URL。
- 产物放在系统临时目录，文档保留脱敏结论。若只有部分页成功，必须判定整章失败并定位阶段。

## Risks / Trade-offs

- 上游和网络随时变化 → 记录实际日期、样本及探测边界，不把一次失败解释为永久不可行。
- 某些页图可能需要特殊解码 → 检查真实返回字节；若仅在浏览器解码成功，单独说明依赖。
- 观察请求可能产生临时签名信息 → 不保存 HAR、浏览器会话或原始网络日志。

## 2026-11-12 实测补记

- 固定参考仓库 `bandcomic/RESTful-bilibili-manga-api` 的提交 `a5a8145eaf3f66e2934a29a76d3df5f8f03f4323`，核对 MIT 许可证。参考其接口参数调查方向，未移植其代码或引入服务依赖。
- 直连、匿名指纹、Android 参数的 HTTP 路径已在《航海王》004（20/20 页）和《非人哉》样本（9/9 页）通过；图片全部为普通 JPEG，完整解码且尺寸与索引相符，不需要浏览器初始化、截图、网页签名或额外解码算法。
- 诊断脚本默认走纯 HTTP；Playwright 和原浏览器启动函数只在显式 `--mode observe` 时导入。HTTP 失败显式退出，不自动回退。
- 系统代理路径的探测出现 SSL 错误，未声称部署网络已经可用。正式接入、按需页图、缓存和权限验证需另立实现变更。证据见 `docs/validation/bilibili-http-images.md`。
