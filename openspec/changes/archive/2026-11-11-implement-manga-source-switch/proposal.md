# 提案：漫画详情页切换数据源 + 拷贝漫画搜索（M31）

## Why

用户希望在作品详情页直接切换数据源查看同作。此前只有首页聚合有源切换；
拷贝漫画也缺少搜索能力（应用 API 维护中，但网页版搜索可用）。

## What Changes

1. 拷贝漫画新增 SEARCH 能力：Playwright 打开 `copy4000.com/search?q=`，
   合并同路径的封面/标题链接后返回结果。
2. 详情页新增「切换数据源」按钮（仅中文且有 SEARCH 的源，排除当前源）：
   按当前作品标题搜索目标源，展示结果列表，点击即跳转目标源详情。
3. 修正详情页来源 chip 硬编码「腾讯动漫」的问题（改用源名映射）。

## 不做

- 自动挑选最佳匹配（避免错配；由用户在结果列表选择）；
- 跨源作品级 ID 映射持久化。
