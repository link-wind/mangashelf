# 提案：阅读器对齐 HOMURA-reader 设计（M22）

## Why

参照 HOMURA-reader（本地漫画阅读器，Vue 3）的阅读器设计，补齐外部漫画阅读器的
交互深度：目前只有滚动/翻页两种模式与基础底栏，缺少阅读方向、双页、点击分区、
横滑翻页与翻页动画。

## What Changes

1. 手势判定移植 HOMURA 阈值（tap / swipe 判别联合）。
2. 设置面板新增：阅读方向（LTR/RTL 日漫）、页模式（单页/双页/首页单排）、
   翻页动画（柔和淡入/极速无动画）；设置持久化。
3. 快捷键 ←→↑↓（RTL 反转）/ Space / Esc 逐层退出 / F 全屏。
4. 沉浸模式：阅读时隐藏站点导航与页脚。

## 不做

- 横向「跟手」拖拽翻页（仅滑动判定）、按作品记忆设置、本地阅读器接入方向/双页。
