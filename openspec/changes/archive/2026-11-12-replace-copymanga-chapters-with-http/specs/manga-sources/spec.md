## ADDED Requirements

### Requirement: 拷贝漫画 HTTP 章节目录

平台 MUST 在不启动浏览器的情况下读取拷贝漫画公开详情和完整章节目录，保持既有章节标识与官网顺序。平台 MUST 复用有效的有界目录缓存；目录无效、缺失或上游失败时明确报错，不自动回退浏览器或返回不完整列表。目录读取 MUST 不依赖个人登录态。

#### Scenario: 首次打开详情

- **WHEN** 用户打开尚未缓存的拷贝漫画作品
- **THEN** 通过 HTTP 获取详情与完整目录，返回所有分组的章节，不启动 Python 或浏览器

#### Scenario: 重复与并发打开详情

- **WHEN** 多个请求同时读取同一作品或读取有效缓存
- **THEN** 复用同一份成功结果，避免重复抓取；缓存有明确过期与容量边界

#### Scenario: 目录不完整或接口变化

- **WHEN** 目录声明数量与实际章节不符、章节重复、解码失败或上游不可用
- **THEN** 返回明确错误，不把部分目录标为成功，不启动浏览器兜底

#### Scenario: 原有章节仍可打开

- **WHEN** 用户从 HTTP 目录打开章节或从历史记录继续阅读
- **THEN** 使用既有章节 ID 和图片解析路径，阅读器按需加载图片
