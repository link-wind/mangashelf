## Context

动机见 proposal.md；对应 DESIGN 4、19、21 节。现有详情通过 Playwright 展开目录，官网实际提供独立的加密目录接口。2026-11-12 已匿名 HTTP 解出《寶石魔女》全部 39 话。

## Goals / Non-Goals

**Goals:** 详情与完整目录使用固定官网 HTTP 请求，沿用现有 API 和章节标识，避免目录缓存失效后启动浏览器。

**Non-Goals:** 本次不替换搜索和章节图片解析，不引入账号登录、通用源框架或付费内容处理。

## Decisions

- HTTP 详情固定访问 `https://www.copy4000.com/comic/{pathWord}` 与同源 `/comicdetail/{pathWord}/chapters`。这是现有 Python 白名单内官网；本机该域名直连成功，而 mangacopy.com 直连被重置。禁止重定向、任意主机与自动切换地址。
- 使用 Jsoup 解析标题、封面、作者和简介；读取详情中的公开目录参数，按官网脚本的 AES-CBC/PKCS7 算法在 Java 解码，不下载执行脚本。目录参数只驻内存，不写日志和文档。
- 校验 build.path_word、每个分组 count、章节 UUID、名称与全局唯一性，保留官网分组/组内顺序，拒绝空目录、截断与重复；不从页头“开始阅读”链接推断目录。
- 详情与目录共用 30 分钟内存缓存，最多 128 部作品；只缓存成功的不可变规范化结果，同作品并发合并。过期失败明确返回，不用旧目录或浏览器兜底。进程重启重新走 HTTP。
- 请求超时、响应体大小和章节数量均设上限；错误响应统一脱敏，网络/协议错误返回 502，源站作品不存在返回 404，非法作品标识返回 400。
- 匿名目录与搜索/图片登录态隔离，详情请求不携带用户 Cookie。
- 目录请求携带详情 HTML 中公开的 `dnts` 参数；与解码参数均仅驻内存。`MANGASHELF_COPYMANGA_PROXY` 显式指定 HTTP 代理，默认直连，不继承系统代理，不自动切换出口。

## Risks / Trade-offs

- [官网结构、加密算法或域名变化] → 明确报错，保留固定样本真实验证脚本；不执行远程 JS。
- [目录公开但图片可能需登录] → 源说明明确目录 HTTP、图片浏览器解析，沿用现有图片权限报错与按需加载。
- [内存缓存重启失效] → 重启后最多重新发两次 HTTP；本次不新增磁盘卷和持久凭据。

## Migration Plan

构建后更新 API/Worker，保留数据库和原浏览器图片缓存；使用原有详情端点验证。回退只需恢复源适配器调用，接口与章节 ID 无需迁移。

## 2026-11-12 实测补记

- Java 生产 HTTP 路径与隔离 Docker 均读取到《寶石魔女》39 章、《海贼王》402 章、《葬送的芙莉蓮》153 章，完整性校验和重复读取一致性通过。原生冷请求曾通过，但重启后同样配置出现上游空目录；暂不能认定该出口稳定。容器当前可复用有效结果，Codex 浏览器已展示完整目录。
- 原生目录阶段每 100 毫秒采样 API 进程树，未见子进程；测试亦验证源适配器详情不调用浏览器。图片阶段单独调用原路径，不以验收浏览器本身作为生产目录依赖。
- 本轮图片完整阅读未通过：固定旧章节及《葬送的芙莉蓮》首话的生产解析报告缺少匿名页图。Python 固定任务的 `LOGIN_REQUIRED` 原本被进程非零退出遮蔽，现显式返回 403 和配置登录态提示。一次独立浏览器探测提取到 1 个地址，不足以证明该话完整可读。
- 目录读取不携带个人登录态；不通过修改官网提供的目录标志或自动切换地址、出口来掩盖限制。目录失败保持显式错误，搜索与图片继续属于既有浏览器路径。
- `./mvnw package` 完成，35 项测试通过；本次新增 4 项 HTTP 协议/缓存测试与 1 项权限错误回归。完整结果见 `docs/validation/copymanga-http-chapters.md`。
