# 提案：首页内容对齐参考站（M14）

## 背景

M13 后视觉与播放体验已对齐 gugu.fan，但首页内容密度明显不足：只有单张轮播
Banner + 少量区块，缺少参考站的时刻表预览、最近更新、榜单、分类与页脚。

## 变更内容

1. 首屏 Banner：4 张轮播（7s）+ 右下缩略图切换 + 徽标/标题/原名/元信息/简介/
   播放·追番·详情；背景用封面轻模糊 + 暗色渐变。
2. 新番时刻表预览：星期 pill 切换，默认今天。
3. 最近更新：资源目录按更新时间倒序 12 部。
4. 本季高分榜：评分 Top10 榜单。
5. 分类入口：五类动漫 pill → `/anime?category=`（索引页支持深链）。
6. 页脚：品牌 + 三组链接。
7. 日历接口补 remarks / episodeCount / categoryName。

## 不做

- 广告位（用户明确要求不接入广告）。
- 播放量/追番人数统计（无数据源，评分维度替代）。
