## Context

见 proposal.md。`docs/validation/bilibili-http-images.md` 已验证匿名指纹与 Android 参数可取得完整索引和普通 JPEG。DESIGN §14、§18、§19 要求保持页序、授权与存储边界；外部内容缓存不作为本地发布资产。

## Goals / Non-Goals

**Goals:** 详情到阅读全程无浏览器；索引不下载图片；只请求视口附近页；重启复用已校验原图；明确处理过期、容量和上游失败。

**Non-Goals:** 不引入数据库缓存表、对象资产迁移、通用任务框架或登录态托管；不读取锁定章节；不改其他数据源的接口行为。

## Decisions

- Java 使用独立 HTTP 客户端调用固定官方 API，默认显式直连，可配置哔哩专用代理；不继承浏览器代理、不在失败时自动切换网络。匿名指纹只存内存，业务码 99 只允许刷新指纹后重试一次；图片令牌失效只允许重新签发一次，不对全量异常重试。
- 详情完整性按官方 `total`、章节列表长度及 ID 唯一性核对；仅 `pay_mode=0` 且 `is_locked=false` 的章节可读。章节 ID 必须与详情中的作品归属匹配。
- 元数据缓存目录和章节索引有效期 30 分钟、10 分钟；页图缓存闲置 7 天过期，默认总额 512 MiB。配置可覆盖，不能传用户指定路径。缓存位于独立本地目录，Compose 挂持久卷；只保存规范化目录、未签名索引及校验后的图片，不保存 Cookie 或令牌。
- 页图缓存以章节、页序、索引版本和图片路径派生的摘要标识，原子写入；文件命中仍经当前元数据权限校验，索引变化后旧版本地址明确失效。同页并发合并，下载并发有上限；过期和超限文件按最旧使用时间清理。
- 章节清单只含完整页序、原始尺寸和站内 URL；不把清单已就绪称为所有图片已下载。页图端点要求登录，返回 `private, no-store`；地址只接受章节 ID、页号及版本，不接收任意 URL、桶或对象 Key。
- HTTP 客户端拒绝非白名单 CDN、非 HTTPS 和重定向；下载有大小、尺寸、超时与格式限制。Java 完整解码后才缓存，不将错误页或部分内容缓存为成功。
- 阅读器使用带尺寸的固定页位和视口观察加载，少量相邻页预取；恢复历史前不请求首批正文，避免续读到末页仍下载章首。翻页模式只加载当前组及相邻组，失败页显示重试按钮与明确提示。保留所有来源的历史与单/双页行为。
- 移除 Java 生产路径中的截图会话、轮询及读取入口。历史验证脚本和独立 Python 采集测试不作为新运行链路，不自动删除旧对象存储图片。

## Risks / Trade-offs

- 非稳定上游接口 → 用少量关键逻辑测试和两个真实样本复验；上游受限直接报错，不回退到截图。
- 原图较大 → 服务端按页取图并限制磁盘总额，前端不预取整章。
- 权限或章节信息变化 → 过期元数据重新获取且失败不交付过期授权，明确有限缓存窗口。
- 持久缓存目录不可写、空间不足或缓存损坏 → 诊断清晰，不向用户报告已缓存成功。

## Migration Plan

部署新版 API 和 Web，新增 API 缓存卷；旧截图对象不迁移、不删除。旧 canvas 会话链接返回明确的已替换状态。回滚应用版本即可恢复旧路径，新缓存可独立保留。

## 2026-11-12 实现与实测补记

- 已实现 Java HTTP 榜单、目录、索引及页图，替换生产截图和轮询。接口参数依据前置
  `bilibili-http-images.md` 验证；参考来源固定提交及许可证保持该记录所述，未移植下载器。
- 匿名指纹实测允许 `/`，已修正白名单并纳入回归。业务码 99 刷新一次，其他业务失败
  不自动重试；图片 401/403 只重新签发一次。未保存个人登录态或签名地址。
- 阅读缓存和哔哩数据源限定 API profile；Docker 验收发现 Worker 无该目录权限后，
  通过限定角色消除无关缓存依赖，没有给 Worker 挂载 API 缓存卷。
- 真实本地与隔离 Docker 通过完整首页链路、20 页和 9 页解码、末页、失败重试、历史与
  390px 布局。章首请求仅 1–3 页，历史续读只请求末页；滚动续读仅请求末尾三页。
- 服务重启及容器强制重建后缓存命中；临时禁用上游的对照中，实时榜单 502、已缓存末页
  仍为 HIT。测试后恢复默认直连，六服务正常且无 OOM。
- Java 30 项测试与前端生产构建通过。详细结果、复现步骤和未覆盖边界见
  `docs/validation/bilibili-http-reader.md`。没有据此声称所有公开作品或长期稳定性已验证。
- 归档后全库严格校验为 10 项通过、1 项失败；失败为未修改的 `external-animations`
  历史需求缺少 SHALL/MUST，本变更及 `manga-sources` 自身严格校验通过。
