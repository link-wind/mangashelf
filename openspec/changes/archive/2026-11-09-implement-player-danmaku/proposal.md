# 提案：播放器皮肤、首页 Banner 与站内弹幕（M13）

## 背景

M12 后界面已切换为 gugu 风格，但播放仍用浏览器原生控制条、首页缺少 gugu 式
大 Banner、也没有弹幕——这三项是「看起来像 gugu」的最后差距。

## 变更内容

1. **自定义播放器**：`components/Player.tsx`——HLS/MP4 加载、自绘控制条
   （进度/缓冲、倍速、弹幕开关、全屏）、大播放按钮、键盘快捷键（Space/←→/F）、
   2.6 秒自动隐藏。
2. **首页 Banner**：本季评分前 5 轮播（6.5s），模糊封面背景 + 封面卡 +
   ★评分/放送星期/收录标记 + 播放或查看本季。
3. **站内弹幕**（V12）：`danmaku` 表 + GET/POST `/api/v1/danmaku`；
   7 轨道滚动层、6 色选择、开关持久化、发送到当前时间点。

## 不做/延后

- 弹弹play 外部弹幕：公开 API 需 AppId（实测 403），留配置位待接入。
- 弹幕顶部/底部固定模式、屏蔽词、举报、频率限制。
