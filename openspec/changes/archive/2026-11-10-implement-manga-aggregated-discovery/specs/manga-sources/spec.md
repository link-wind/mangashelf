# manga-sources 增量：多源聚合推荐（中文源）

## ADDED Requirements

### Requirement: 多源聚合推荐

漫画首页 MUST 提供跨中文数据源的聚合推荐，且不展示非中文源或非中文标题内容。

#### Scenario: 综合榜融合多源

- **WHEN** 用户打开漫画首页并选择「综合」
- **THEN** 展示综合热榜（多源作品按融合得分排序、同作只出现一次）以及各中文源的原始分区

#### Scenario: 非中文源被排除

- **WHEN** 某个数据源声明为非中文（如 MangaDex）
- **THEN** 该源不参与聚合推荐，也不出现在漫画首页的源切换中

#### Scenario: 非中文内容被过滤

- **WHEN** 聚合结果中出现纯非中文标题
- **THEN** 该条目不出现在综合榜中

#### Scenario: 单源失败

- **WHEN** 某个中文源请求失败或超时
- **THEN** 其余源正常展示，页面以提示说明失败源，不整体报错
