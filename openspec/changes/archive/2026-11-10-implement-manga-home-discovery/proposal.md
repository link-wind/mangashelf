# 提案：漫画首页发现流（推荐 + 多榜单）

## Why

当前 /manga 是「本地漫画网格 + 右侧单榜单」两栏；本地书库几乎为空时整页无内容，
用户看不到推荐与排行。参照哔哩哔哩漫画/快看漫画首页：以 banner + 多行推荐/榜单
为主，本地书库作为其中一块。

## What Changes

1. 规则源支持**多分区榜单**（`rank.sections`）：同一页面内用块选择器拆分
   编辑推荐/男生榜/女生榜/畅销榜；引擎单次抓页解析全部分区。
2. 新增 `GET /api/v1/manga-sources/{source}/sections?limit=` 聚合返回各分区；
   代码源（MangaDex/哔哩）默认降级为单分区「热门」。
3. V16 迁移把腾讯动漫规则升级为四分区。
4. 前端重写 /manga：源切换 + 自动轮播 hero + 横向分区卡片行（前三名徽标）
   + 本地漫画区块；源选择持久化到 localStorage。

## 不做

- 个性化推荐（无用户画像）；分类筛选页；分区「查看全部」独立页；
- 哔哩/MangaDex 多分区（其接口无对应数据）。
