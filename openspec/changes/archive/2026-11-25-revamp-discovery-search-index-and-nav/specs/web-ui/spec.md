# web-ui Specification Delta

## ADDED Requirements

### Requirement: 顶栏精简与「我的」个人中心

桌面端顶部导航 MUST 收口为 5 个主入口：首页（`/`）、番剧（`/anime`）、漫画（`/manga`）、时刻表（`/schedule`）与我的（`/me`，仅登录态显示）。「我的」页面 MUST 统一承载继续追更、收藏与历史三个视图，并在各视图中提供「全部 / 动画 / 漫画」类型筛选；旧路径 `/shelf`、`/history`、`/manga-index`、`/manga-ext` MUST 兼容重定向到对应新视图。

#### Scenario: 登录后在「我的」同时管理动画与漫画
- **WHEN** 已登录用户打开 `/me` 并切换「继续追更 / 收藏 / 历史」与「全部 / 动画 / 漫画」筛选
- **THEN** 正确展示对应类型的动画与漫画条目；取消收藏提供 Toast 反馈，且未读过的外部漫画收藏在目录库存在封面时展示有效封面

#### Scenario: 漫画页双 Tab 切换
- **WHEN** 用户访问 `/manga` 并切换「发现推荐」与「分类索引」Tab
- **THEN** 视图在推荐流与分类分页索引间切换，URL 参数同步更新，且顶部提供统一的全流漫画搜索框

### Requirement: 索引分类筛选、页码分页与前端路由按需拆包

番剧索引（`/anime`）与漫画索引（`/manga?tab=index`）MUST 提供多维分类筛选与页码分页导航（含上一页、页码按钮、下一页与总数），所有筛选条件与页码 MUST 同步至 URL 查询参数以支持刷新与浏览器前进后退。站点路由 MUST 采用路由级懒加载拆包，避免播放器（`hls.js`）与阅读器阻塞首屏主包加载。

#### Scenario: 番剧与漫画索引分类翻页
- **WHEN** 用户在番剧索引或漫画索引组合筛选条件并切换至第 2 页后刷新浏览器
- **THEN** 筛选条件、当前页码与列表结果保持一致，总数与总页数准确反映当前查询条件
