# 提案：跨源同作合并卡片（M26）

## Why

M25 的综合热榜只做标题级去重：同一作品在不同源/不同译名/不同版本下仍会出现
多张卡。用户要求进一步做作品级合并——一张卡代表一部作品，标注可读源数量，
并选择最合适的源作为阅读入口。

## What Changes

1. 聚合结果在 RRF 融合后增加**作品聚簇**：
   - 归一化标题精确相等优先合并；
   - 高阈值（0.9）字符二元组相似度兜底近似标题；
   - 保留括号内容（“全彩版/番外篇”不被误合并）。
2. 每个聚簇输出一个条目：得分累加、展示分最高的可读版本、`sourceCount`
   与 `sources`（源名列表）；阅读入口优先中文源站内阅读，其次站外。
3. `/api/v1/manga-discovery` 行条目升级为 DiscoveryItem（新增 sourceCount/sources）。
4. 前端卡片/hero 显示「N 源」徽标；综合热榜不再出现同作多卡。

## 不做

- 跨语言别名匹配（需词典/外部检索，MangaDex 已从聚合源排除）；
- 人工合并/纠错 UI；作品级持久化 ID（每次请求内存聚簇）。
