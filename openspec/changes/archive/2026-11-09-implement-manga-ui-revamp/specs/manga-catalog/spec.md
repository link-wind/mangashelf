## ADDED Requirements

### Requirement: 沉浸式漫画阅读

阅读器 MUST 全屏沉浸显示，提供顶/底浮层与页码导航，并记住阅读位置。

#### Scenario: 继续阅读

- **WHEN** 用户打开上次读过的章节
- **THEN** 阅读器定位到上次页码，浮层可点击唤出，显示上一话/下一话与页码滑杆

### Requirement: 漫画详情章节格

详情页 MUST 以数字格展示章节，并支持语言与排序切换。

#### Scenario: 浏览章节

- **WHEN** 用户打开漫画详情
- **THEN** 看到大封面、信息与章节格；点击章节进入沉浸阅读
