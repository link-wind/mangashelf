# 提案：漫画页面与阅读器改版（M21）

## Why

漫画索引与详情沿用通用卡片/列表布局，阅读器仍是普通页面内嵌图片，与哔哩哔哩漫画
的阅读体验差距明显。

## What Changes

1. 漫画索引改两栏：左本地漫画，右侧热门榜纵向榜单 + 外部入口。
2. 外部漫画详情：大封面 + 信息 chips + 简介折叠 + 开始/继续阅读 + 章节数字格。
3. 阅读器（本地/外部）统一为沉浸式：隐藏导航、顶栏与底栏浮层、页码滑杆、
   上一话/下一话；外部支持滚动/翻页模式与续读。
4. 页图改走同源图片代理（磁盘缓存）。

## 不做

- 亮度/背景色调节、滑动翻页手势、本地条漫连续滚动。
