# 设计：漫画 UI 改版（M21）

## D1. 沉浸式阅读器

`body.reader-open` 隐藏站点导航与页脚；阅读器使用文档流滚动（fixed 高滚动容器
在长列表下会出现位图不合成）。顶/底栏 fixed 覆盖，3 秒自动隐藏，点击或移动唤出。

## D2. 续读

服务端进度优先：进入章节读取 `manga-progress`，同章且 page>1 时把目标页设为
eager 预加载，等 `load` 后再滚动定位（懒加载图片未加载时高度为 0，直接滚会错位）。

## D3. 页图

统一走 `/api/v1/external-manga/image` 同源代理（白名单 + 磁盘缓存），
规避跨域图片在特定容器中的渲染问题。

## D4. 详情页

封面 208px、信息区（标题/别名/chips/简介折叠）、主按钮（开始或继续阅读）、
章节数字格（话号 + 页数），语言与排序切换。
