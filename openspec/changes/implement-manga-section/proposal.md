# 提案：漫画专区（M15）

## 背景

M1 完成了漫画阅读全链路（上传 → CBZ 解析 → 发布 → 阅读器 → 进度），但入口埋在
「作品详情」里，首页与导航都是动画导向，漫画能力几乎看不见。

## 变更内容

1. `GET /api/v1/manga`：只列有已发布章节的可见作品，封面取首章首页缩略图，
   游标分页 + 标题搜索。
2. `GET /api/v1/manga/{id}`：作品 + 章节（逐章已读页数）+ 封面 + 续读目标。
3. 前端 `/manga` 索引、`/manga/:id` 详情；首页漫画区块（继续阅读 + 更新）；
   导航新增「漫画」。

## 不做

- 自定义封面（先用首页缩略图）、漫画标签体系、条漫连续滚动模式、章节评论。
